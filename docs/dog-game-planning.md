## 一、企劃概述

### 1.1 目標

本企劃為「犬版」飼養前評估遊戲的完整規格文件。犬版遵循相同的 8 步驟主流程與共用元件架構，所有犬類專屬內容集中在 `app/data/species/dog/` 設定檔，不重複複製頁面元件、不在元件內散落 `species === "dog"` 條件判斷。

玩家品種選擇限定為**柴犬**與**米克斯**兩種，其他品種（吉娃娃、貴賓犬、邊境牧羊犬、拉布拉多、杜賓犬、英國古代牧羊犬）僅在「過往經驗」階段出現。品種的考驗依玩家選擇的品種呈現對應題組。

### 1.2 犬的核心照護差異（與其他物種相比）

| 差異點 | 說明 | 遊戲設計重點 |
|---|---|---|
| 每日必須外出散步 | 狗狗的排泄、活動與感官刺激高度仰賴外出；許多個體（尤其柴犬）傾向在戶外如廁 | Walking 互動活動 + 柴犬考驗2 |
| 行為問題需要正確處置 | 吠叫、亂咬、隨地如廁是最常見的新手困境，錯誤應對（打罵）反而加劇問題 | 日常行為照顧三子情境 |
| 品種特性影響照護需求 | 柴犬掉毛量大、戶外如廁傾向強；米克斯體型與個性因個體差異大，需要更多觀察與適應 | 品種的考驗（依品種呈現不同題組） |
| 忙碌時需人接手 | 超過八小時無人照護可能引發焦慮、吠叫或破壞行為；臨時外出需提前安排 | 疲憊忙碌的日子情境 |
| 高齡照護準備 | 行動退化、排泄照護、醫療頻率增加；高齡前應提前規劃醫療基金與環境調整 | 高齡後的照顧準備情境 |

### 5.2 第一天適應新家（arrival-adjustment）

**stageLabel**：接回家  
**情境**：{petName} 剛走進陌生的新家，躲在外出籠旁觀察，家人都很想立刻和牠打招呼。  
**topic**：適應新家與安全感  
**reportSummary**：第一天適應新家時，狗狗可能因陌生而躲藏或緊張；保留安靜、安全且能退回的空間，等待牠主動探索。

**問題**：你會怎麼做？

| 選項 | id | 正確性 | 回饋 |
|---|---|---|---|
| 強行抱出來 | `force-pick-up` | ❌ 不適當 | 這個做法可能讓牠更緊張。被強行抱起會讓小狗失去退路，增加防衛反應，也可能降低牠對新環境的安全感。先放低互動強度，讓牠用自己的速度探索。 |
| 保持距離，給牠安靜適應的時間 | `quiet-explore` | ✅ 正確 | 剛到新家的小狗需要先觀察環境。保持距離並提供安靜、安全的空間，能減少壓力，讓牠以自己的速度建立安全感。準備乾淨飲水與可休息的角落，等牠主動靠近後再慢慢增加互動。 |
| 持續靠近並呼喚牠 | `keep-calling` | ❌ 不適當 | 持續靠近與呼喚會增加刺激，讓還在適應中的小狗難以安心觀察，可能變得更緊張或躲避。先退開一些，讓牠保有安靜且能退回的安全空間。 |
| 坐在附近陪牠，但每隔一下就伸手摸摸看 | `quiet-nearby` | ❌ 不適當 | 想陪伴牠的心意很好，但頻繁伸手仍可能讓剛到家的小狗感到壓力，難以真正休息。可以安靜待在附近，先不主動碰觸，等牠願意靠近時再互動。 |

**答對時顯示（做得很好）**

**鼓勵話語**：你知道第一天不要給 {petName} 太多壓力，做得很好！給牠時間和空間，才能讓牠以自己的速度建立安全感。

**狗狗小知識**：剛到新家的小狗需要先觀察環境。保持距離並提供安靜、安全的空間，能減少壓力，讓牠以自己的速度建立安全感。準備乾淨飲水與可休息的角落，等牠主動靠近後再慢慢增加互動。

**知識來源**：D3（`犬-習性行為與相處技巧.md`「初次接回・環境適應」）；D2（`犬-飼養前評估.md`「接回家準備」）

### 5.3 日常行為照顧（behavior）

**stageLabel**：日常照護  
**topic**：日常行為照顧  
**設計說明**：共三個子情境，依序呈現：吠叫 → 亂咬 → 如廁。每個子情境為獨立多選題。

---

#### 5.3.1 子情境 B-1：牠一直吠叫，該怎麼辦？（behavior-barking）

**情境**：晚上你正在休息，{petName} 突然對著門口一直吠叫。你看見牠有些警覺，也注意到附近有聲音經過。

**問題**：你應該怎麼做？（請選出所有正確選項）

| 選項 | id | 正確性 | 回饋 |
|---|---|---|---|
| 提供遊戲與互動，增加安全感 | `bark-play` | ✅ 正確 | 遊戲與溫和互動能提供安全感，也有助於把注意力轉向合適的活動。 |
| 帶牠適量散步，消耗精力 | `bark-walk` | ✅ 正確 | 依小狗狀況安排適量散步，有助於滿足活動需求並降低累積的焦躁。 |
| 牠一直叫就大聲罵牠，讓牠知道不可以 | `bark-scold` | ❌ 不適當 | 單純責罵可能增加緊張，也無法處理吠叫背後的原因。應先觀察聲音、壓力、活動量或身體不適等可能的觸發因素。 |
| 若情況持續或影響生活，尋求獸醫或行為專家協助 | `bark-expert` | ✅ 正確 | 當狀況持續或影響生活時，及早諮詢獸醫或行為專家能更完整找出原因。 |

**必選正確選項**：`bark-play`、`bark-walk`、`bark-expert`  
**必避免選項**：`bark-scold`

**全部正確時顯示（做得很好）**

**鼓勵話語**：你選擇了理解 {petName}，而不是責罵牠，做得很好！找出吠叫的原因才能真正幫助牠。

**狗狗小知識**：吠叫是狗狗的溝通方式。先觀察**何時、對什麼叫**，再判斷是警戒、害怕、無聊或不舒服。責罵只可能暫時停止聲音，卻未處理原因；若持續發生，可記錄**頻率、時間與觸發情境**後詢問專業人員。

**知識來源**：D3（`犬-習性行為與相處技巧.md`「吠叫行為・溝通方式」）

---

#### 5.3.2 子情境 B-2：牠開始亂咬東西，該怎麼辦？（behavior-chewing）

**情境**：你回到客廳時，發現 {petName} 正在咬桌腳旁的物品。旁邊還有一些不能讓牠碰到的小東西。

**問題**：你應該怎麼做？（請選出所有正確選項）

| 選項 | id | 正確性 | 回饋 |
|---|---|---|---|
| 提供多樣化且安全的啃咬玩具 | `chew-toys` | ✅ 正確 | 安全的啃咬玩具能提供合適的探索出口，也能讓牠把咬的需求放在正確物品上。 |
| 看到牠咬東西就立刻打牠或嚇牠 | `chew-punish` | ❌ 不適當 | 打罵或驚嚇可能造成壓力、破壞信任，也不一定能解決探索與情緒需求。先收好危險物品，並把牠引導到安全的啃咬玩具。 |
| 把有害物品收好，避免牠接觸 | `chew-store-hazards` | ✅ 正確 | 先管理環境能降低誤食與受傷風險，也讓小狗更容易練習安全的選擇。 |
| 若情況嚴重或持續，尋求獸醫或行為專家協助 | `chew-expert` | ✅ 正確 | 持續或嚴重的行為改變值得讓獸醫或行為專家協助評估。 |

**必選正確選項**：`chew-toys`、`chew-store-hazards`、`chew-expert`  
**必避免選項**：`chew-punish`

**全部正確時顯示（做得很好）**

**鼓勵話語**：你知道亂咬不是搗亂，而是自然的需求，做得很好！引導而非懲罰，才是正確的教導方式。

**狗狗小知識**：啃咬是**狗狗的自然行為**，幼犬換牙、探索、無聊或壓力都可能讓啃咬增加。選擇符合體型且不易碎的玩具，並在**咬對物品時立即鼓勵**；玩具破損時要更換，避免誤食。

**知識來源**：D3（`犬-習性行為與相處技巧.md`「啃咬行為」）；D5（`犬-環境設備與日常照護.md`「啃咬玩具選擇」）

## 六、照護評估報告（Step 7：Report）

### 6.1 評估面向（assessmentDimensions）

報告依以下五個面向統計旅程中的選擇表現，以定性描述呈現，不以數字評分：

| 面向 | 對應知識來源 | 評估重點 |
|---|---|---|
| 物種認識 | D1、D2 | 對狗狗基本習性、品種特性、每日外出需求的理解 |
| 飲食管理 | D1 | 飼料選擇、不可餵人食、飲水供應 |
| 環境與安全 | D5 | 危險物品排除、休息空間設置、外出準備 |
| 健康觀察 | D4 | 症狀記錄習慣、危急判斷、避免自行用藥 |
| 行為與互動 | D3 | 吠叫/啃咬/如廁的正確應對、正向引導而非懲罰 |

### 6.2 報告文字設計原則

- 不設定通過/不通過門檻，不計算百分比
- 每個面向給予具體的知識回顧，指出玩家在哪些場景做出了好的選擇，哪些場景還有學習空間
- 最終提供照護資源連結（農業部犬篇指南、尋找獸醫）
- 強調「本結果供學習參考，不能取代個體評估與獸醫諮詢」

### 6.3 每日照護時間（dailyCareBreakdown）

**每日約需安排 2～4 小時**

| 項目 | 時間 |
|---|---|
| 外出散步（至少一次，建議兩次） | 20–30 分鐘/次 |
| 餵食換水 | 15–30 分鐘 |
| 陪伴互動 | 30–60 分鐘 |
| 清潔梳理 | 15–30 分鐘 |
| 觀察與記錄 | 5–10 分鐘 |

> **資料格式參考**：對應 `dog/report.ts` 的 `dailyCareBreakdown` 格式。

## 七、補充說明

### 7.1 品種考驗的 fallback 邏輯

`getDogBreedChallengeScenarios` 函式目前在 breedId 找不到對應資料時，回退（fallback）至 `shiba` 的題組。**米克斯（`mixed`）題組需開發完成後加入 `breed-challenges.ts`**，避免觸發 fallback。

### 7.2 米克斯犬挑戰題組的設計備註

米克斯考驗2題的知識點（個性因個體差異大）相關中文學術文獻有限，目前以農業部指南與收容所實務建議為主要知識來源。若後續需要補充英文文獻，可參考 ASPCA（https://www.aspca.org）或 Humane Society（https://www.humanesociety.org）的混種犬照護資源。

### 7.3 行為三子情境的呈現順序

`behavior-barking → behavior-chewing → behavior-toileting` 三個子情境在 journey 中共用一個 `"behavior"` 節點。實作時應依序呈現，或依遊戲設計決定是否允許玩家選擇子情境順序。
