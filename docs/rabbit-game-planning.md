## 一、企劃概述

### 1.1 目標

在既有的「犬版」與「貓版」飼養前評估遊戲流程之上，新增**兔版**內容。兔版遵循相同的 8 步驟主流程與共用元件架構，所有兔類專屬內容集中在 `app/data/species/rabbit/` 設定檔，不重複複製頁面元件、不在元件內散落 `species === "rabbit"` 條件判斷。

### 1.2 兔的核心照護差異（與犬貓相比）

| 差異點 | 說明 | 遊戲設計重點 |
|---|---|---|
| 草食性 | 主食必須是牧草（>80%），不能以紅蘿蔔代替 | 餵食場景強化牧草重要性 |
| 非常怕熱 | 無汗腺，只靠耳朵散熱，28℃以上要特別注意 | 高溫事件場景 |
| 隱藏不適 | 生性隱藏痛苦，12小時無進食即危急 | 日常觀察場景設計 |
| 繁殖力極強 | 4-5月齡可繁殖，建議及早絕育 | 絕育議題場景 |
| 不可洗澡 | 乾洗粉也不適合，梳毛才是日常護理 | 梳毛互動場景 |
| 骨骼脆弱 | 錯誤抱法可能致腰椎受損、下半身癱瘓 | 抱兔互動場景 |
| 食糞正常現象 | 盲腸便屬正常，飼主需了解 | 知識測驗場景 |

## 三、物種選擇階段（Step 1：SpeciesStep）

物種選擇包含 5 個子頁面，所有子頁面資料來自 `rabbit.selection` 設定。

### 3.1 子頁面流程（speciesSubPage）

```

1-4 照護承諾確認
1-5 選擇摘要確認
```

---

### 3.2 兔種選擇（1-1）

> 畫面說明：說明「迷你兔」不是永遠長不大，而是小型混種兔的俗稱，讓玩家選擇打算飼養的兔子類型。

**標題**：你打算迎接哪種兔子？

**提示文字**：  
「迷你兔」是市售對小型混種兔的俗稱，長大後約 1.2–2.5 公斤，不是永遠長不大。不同體型的兔子在籠舍空間、牧草消耗量與醫療費用上會有差異。

**選項**（`selectionId`）：

| selectionId | 顯示名稱 | 副說明 | 備註 |
|---|---|---|---|
| `mini-rabbit` | 迷你兔（小型混種兔） | 成體約 1.2–2.5 公斤 | 最常見市售俗稱 |
| `dwarf-rabbit` | 侏儒兔 | 成體約 0.7–1.1 公斤（如荷蘭矮耳兔） | 體型最小，高度建議個體評估 |
| `large-rabbit` | 大型兔 | 成體約 3–5 公斤（如紐西蘭大白兔等） | 需要更大籠舍與活動空間 |

**知識來源**：R1（`兔.md`「迷你兔迷思」段落）；農業部兔篇文字版第 1–2 頁

### 3.3 來源確認（1-2）

**標題**：你打算從哪裡迎接兔子？

**說明文字**：不同來源代表不同的照護起點。無論從哪裡迎接，迎接前都應先評估自己的照護能力。

**選項**：

| 選項 | 說明 |
|---|---|
| 收容所或中途領養 | 可能是成兔，過往照護史不明，需耐心適應 |
| 合法繁殖業者 | 確認業者提供健康紀錄與適當離乳時間（至少 6–8 週） |
| 寵物店 | 注意詢問兔子年齡、離乳時間與健康紀錄 |
| 朋友或其他管道 | 確認兔子的飲食、健康與行為資訊 |

**知識來源**：R2（`兔-飼養前評估.md`「物種認識與照護承諾」）

### 3.4 兔子名字輸入（1-3）

### 3.5 照護承諾確認（1-4）

> 設計原則：依照 AI_PROJECT_GUIDE.md「不做評分門檻」原則，此頁為資訊確認，不判定合格/不合格。

**標題**：迎接 {petName} 之前，請確認這些照護承諾

**問題設計（確認式，玩家閱讀後點選「我了解了」繼續）**：

**Q1：照護年限**  
「兔子的壽命平均 6–13 年，現代寵物兔通常能活 7 年以上。你準備好長期陪伴 {petName} 嗎？」  
→ 來源：R1（`兔.md`「概述・壽命」）；R2（`兔-飼養前評估.md`「物種認識與照護承諾」）

**Q2：牧草是主食**  
「兔子需要以乾草或牧草為主食（佔每日進食量 80% 以上），不是以紅蘿蔔或飼料為主。你能長期穩定供應牧草嗎？」  
→ 來源：R1（`兔.md`「飲食與飲水・成兔每日餵食比例」）；農業部兔篇圖文版第 8 頁

**Q3：隱藏不適的物種**  
「兔子生性隱藏身體不適，若 12 小時完全無進食就是非常危急的情形，需立刻就醫。你已找好可以看兔子的獸醫師嗎？」  
→ 來源：R4（`兔-健康醫療與異常觀察.md`「危急警訊」）；R2（`兔-飼養前評估.md`「健康與醫療」）

**Q4：繁殖力極強**  
「兔子繁殖力極強，3–4 月齡即可能具繁殖能力，公母混養很快會大量繁殖。你計畫如何管理繁殖問題？」  
→ 來源：R1（`兔.md`「繁殖力極強」）；R3（`兔-習性行為與相處技巧.md`「繁殖」）

## 四、領養前準備階段（Step 2：Preparation）

### 4.1 佈置房間（Task 0：RoomPreparation）

玩家在房間畫面中拖放物品，設置兔子的生活環境，並移除危險物品。

#### 4.1.1 應放置的安全物品（roomItems）

| id | 顯示名稱 | 說明文字 | 必要性 | 知識來源 |
|---|---|---|---|---|
| `hay-rack` | 牧草架 | 牧草是兔子主食（>80%），必須隨時可取用。牧草架能保持牧草乾淨不被踩踏。 | 必要 | R1 飲食段落；農業部圖文版第 8 頁 |
| `heavy-water-bowl` | 較重的飲水碗 | 選擇較重的碗避免打翻；比滾珠瓶更受兔子歡迎，也能觀察飲水量。 | 必要 | R1「飲水」段落 |
| `litter-box` | 便盆（附吸附墊料） | 兔子傾向固定區域排泄，可訓練使用便盆；需定期清潔以避免尿灼傷。 | 必要 | R1「排泄空間」段落 |
| `hiding-box` | 躲藏箱/小屋 | 兔子需要隨時可退避的躲藏處，減少緊迫。 | 必要 | R1 環境段落；R5 適應期 |
| `anti-slip-mat` | 防滑墊 | 兔子骨骼脆弱，滑溜地板會造成受傷。地面必須防滑。 | 必要 | R1「生活環境」；R2 環境段落 |
| `cooling-mat` | 陶板涼感墊 | 兔子非常怕熱（無汗腺），高溫時需要涼感墊幫助散熱。 | 重要 | R1「環境溫度・最適 15–25℃，28℃以上觀察高溫徵兆」 |
| `chew-toy` | 咀嚼玩具（木製） | 兔齒終生生長，需要磨牙材料；木製玩具安全，可轉移啃咬天性。 | 重要 | R1「磨牙」；R3「啃咬行為」 |
| `dig-box` | 挖掘箱 | 挖掘是兔子天性，挖掘箱可滿足行為需求，減少刻板行為。 | 建議 | R1「行為與活動需求・環境豐富化」 |
| `fence-pen` | 圍片/柵欄 | 以圍片隔出兔子活動區域，限制活動範圍並保護家具。 | 建議 | R1「生活環境」 |

#### 4.1.2 危險物品（hazards，應移除）

| id | 顯示名稱 | 危險原因 | 知識來源 |
|---|---|---|---|
| `cable` | 電線 | 兔子有強烈啃咬天性，咬電線可能觸電或食入異物 | R3「啃咬行為」 |
| `toxic-plant` | 有毒植物（蔥/蒜/洋蔥盆栽等） | 蔥、蒜、洋蔥對兔子有毒；兔子可能食入 | R1「避免餵食」段落 |
| `plastic-item` | 塑膠製品（置於地面的塑膠容器等） | 兔子可能啃咬塑膠並食入，造成腸胃疾病 | R3「啃咬行為」 |
| `slippery-floor` | 光滑地板（無防滑墊的磁磚/木地板） | 兔子骨骼容易脆裂，滑落容易受傷甚至腰椎受損 | R1、R3「不可從耳朵拎起・骨骼脆裂」 |
| `high-platform` | 過高的平台/桌面（無保護） | 兔子骨骼脆弱，從高處落下容易受傷 | R1 環境段落 |
| `foam-mat-with-edges` | 有邊角的海棉墊 | 兔子啃食泡棉可能食入異物造成腸阻塞 | R4「異常行為・啃咬」 |

## 五、飼養生活旅程（Steps 3–6：LifeJourney）

生活旅程設計為 **4 個生命階段**，每個階段含多個事件（events），每個事件有**情境說明**和**互動問題**。

### 5.1 生命階段設計

| lifePhase | 階段名稱 | 主要照護重點 |
|---|---|---|
| A | 到家適應期 | 安置、探索、建立信任、觀察初期排便與進食 |
| B | 幼兔/成長期 | 牧草主食、絕育時機、社交與環境豐富化 |
| C | 成兔穩定期 | 日常觀察、換毛期照護、定期健康檢查 |
| D | 高齡期 | 老化徵兆觀察、醫療需求增加、飲食調整 |

---

### 5.2 Phase A：到家適應期

#### 事件 A-1：{petName} 第一天到家

**情境**：{petName} 剛到家，你打開外出籠讓牠自己走出來探索。牠躲進了你準備的躲藏箱裡，不太出來。

**問題**：你會怎麼做？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 把{petName}從箱子裡抱出來，讓牠熟悉環境 | ❌ 不適當 | 躲藏是兔子面對新環境的正常反應，不是失敗。強迫牠出來只會增加緊迫，需要給牠自己決定何時出來的空間。（R5；R3 人兔互動段落） |
| 保持安靜，讓牠自己決定何時出來探索 | ✅ 正確 | 兔子面對新環境需要時間，讓牠主動探索是建立信任的第一步。提供可隨時躲藏的空間，減少緊迫。（R5；R3「不逼迫互動」） |
| 大聲呼喚牠的名字，讓牠認識你 | ❌ 不適當 | 兔子聽覺敏銳，突然的大聲會造成緊迫。應保持安靜、動作緩慢，讓牠習慣你的存在。（R3 人兔互動；R1「易受驚嚇緊迫」） |
| 帶貓狗鄰居來讓{petName}交新朋友 | ❌ 不適當 | 適應期不應引入其他動物，新環境加上陌生動物氣味與聲音會大幅增加緊迫。（R5 家庭分工段落） |

**知識來源**：R5（`兔-適應期教學.md`「初到家的安置與環境探索」）；R3（`兔-習性行為與相處技巧.md`「人與兔子互動」）

---

#### 事件 A-2：初次餵食

**情境**：{petName} 到家的第一天晚上，你發現牧草架裡的牧草吃剩很多，{petName}也只喝了少量的水。

**問題**：你的判斷是？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 正常，到新環境緊迫會影響食慾，繼續觀察 | ✅ 謹慎觀察 | 到新環境食慾下降在短期內屬可能現象，但兔子必須持續進食，需每日記錄食慾、飲水與排便狀況。若 12 小時完全無進食即為危急。（R6；R4 危急警訊） |
| 換成{petName}最喜歡吃的紅蘿蔔，讓牠有食慾 | ❌ 不適當 | 紅蘿蔔屬蔬菜，不能替代牧草。大幅改變食物種類可能加重腸胃不適，也容易造成消化道問題。（R1「飲食・不以紅蘿蔔替代主食」） |
| 只要牠沒有完全不吃，12 小時後再觀察就好 | ⚠️ 需謹慎 | 12 小時完全無進食才是「非常危急」，但仍需每日記錄進食量，並在看到異常趨勢時立即聯繫獸醫。（R4 危急警訊；R6 日常觀察） |
| 立刻帶去看獸醫 | ⚠️ 依狀況 | 若只是食慾略減，先觀察並記錄；但若完全不吃、呼吸異常、腹部緊繃或步態不穩，則應立即就醫。（R4 危急警訊） |

**知識來源**：R4（危急警訊・12 小時完全無進食）；R6（`兔-日常觀察與照護紀錄.md`）

---

#### 事件 A-3：{petName}的神奇糞便

**情境**：你在餵食時發現 {petName} 直接把嘴湊到屁股旁邊，吃了一種看起來像葡萄串、閃亮亮的東西。你以為牠生病了！

**問題**：這個行為正確的解讀是？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 這是病態行為，要立刻帶去看獸醫 | ❌ 誤解 | 這是兔子正常的「食糞行為（Caecotrophy）」，吃的是盲腸便（俗稱葡萄便），含有腸道菌叢合成的必需營養素，屬正常生理現象。（R3「行為訊號・食糞」；R1「食糞（盲腸便）」） |
| 這是食糞行為，盲腸便是必要的營養來源，完全正常 | ✅ 正確 | 盲腸便不同於一般糞便，通常在清晨或傍晚排出並立即食入，是兔子吸收必需營養素的重要方式。不應阻止或清除。（R3；R1） |
| 牠在吃地板上撿來的東西，要更頻繁清潔籠子 | ❌ 誤解 | 牠在吃自己剛排出的盲腸便，這是正常行為，不需增加清潔頻率（一般糞便的清潔頻率維持即可）。 |

**知識來源**：R1（`兔.md`「食糞（盲腸便）」）；R3（`兔-習性行為與相處技巧.md`「行為訊號・食糞」）

**情境**：{petName} 已經適應一段時間，今天想試著抱起牠。你應該怎麼做？

### 5.4 Phase C：成兔穩定期

#### 事件 C-1：大量脫毛

**情境**：某天早上你發現 {petName} 的籠子裡有大量的毛，{petName} 也在自己梳毛，毛一直掉。

### 10.2 getSpeciesConfig 更新

```typescript
export function getSpeciesConfig(species: string | undefined): SpeciesConfig {
  if (species === "cat") return speciesConfigs.cat;
  if (species === "rabbit") return speciesConfigs.rabbit;
  return speciesConfigs.dog; // default
}
```

### 10.4 注意事項

1. **不破壞犬版既有流程**：所有兔版新增內容集中在 `rabbit/` 設定檔
2. **修改前先 git status 確認**
3. **修改後執行**：`corepack pnpm run build` + `corepack pnpm test` + `corepack pnpm run lint`
4. **食糞行為（盲腸便）**為必須包含的知識點，避免飼主誤以為異常就醫
