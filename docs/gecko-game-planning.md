## 一、企劃概述

### 1.1 目標

本企劃為「小型地棲性守宮版」飼養前評估遊戲的完整規格文件。遊戲以互動旅程的方式，讓使用者在決定飼養守宮之前，親身體驗日常照護的情境與挑戰——從佈置爬蟲缸、接回守宮的第一天、每日健康巡視、餵食與補鈣，到脫皮照護與突發健康狀況的應對。

遊戲設計的核心不是評分或評判，而是讓使用者帶著真實情境的感受，自己形成對「我能不能好好養一隻守宮」這個問題的答案。所有照護知識以回饋文字傳遞，所有情境選擇不設失敗終止，玩家無論選了什麼，都會看到對應的說明與引導。

小型地棲性守宮版遵循相同的 8 步驟主流程與共用元件架構，所有守宮專屬內容集中在 `app/data/species/gecko/` 設定檔，不重複複製頁面元件、不在元件內散落 `species === "gecko"` 條件判斷。

### 1.2 小型地棲性守宮的核心照護特點

| 差異點 | 說明 | 遊戲設計重點 |
|---|---|---|
| 外溫動物，需人工建立溫度梯度 | 守宮無法自行調節體溫，飼主必須在爬蟲缸內設置暖側（28–32°C）與涼側（22–25°C），讓牠依需求自行移動調節。環境溫度不足時，消化、免疫與行動力都會受影響。 | §4.1 爬蟲缸佈置（加熱片/燈選擇）、§5.3.2 每日健康巡視（溫度確認） |
| 夜行性，白天多靜止或躲藏 | 小型地棲性守宮（如豹紋守宮、肥尾守宮）多在傍晚至夜間活動，白天通常躲在躲避屋休息。新手常誤以為白天不動表示生病，或以強光照射企圖「叫醒」牠。 | §5.2.2 接回家第一天（不打擾安置）、§5.3 D-1 拒食情境 |
| 完全獨居，不可混養 | 守宮具強烈領域性，尤其雄性相遇必然打鬥。即使雌性也有競爭行為，混養風險高。飼養守宮必須**每隻單獨一缸**。 | §3 物種選擇（說明獨居）、§4.0 居住確認、§6.7 延伸情境 |
| 昆蟲食物鈣磷比不足，必須補鈣 | 活昆蟲（蟋蟀、麵包蟲等）磷含量遠高於鈣，長期餵食未補鈣的昆蟲會導致代謝性骨病（MBD）。每次餵食前須以鈣粉沾裹昆蟲（gut dusting），並定期以蔬果強化餌料（gut loading）昆蟲的營養價值。 | §5.2.3 第一餐（補鈣操作）、§5.3.2 每日巡視（補鈣碟確認）、§5.5.2 生病題（MBD 知識） |
| 底材選擇攸關生死，禁用細沙 | 守宮在爬蟲缸中覓食時可能誤食底材，細沙、爬蟲沙等鬆散底材若被吞入，會在消化道堆積造成腸阻塞，嚴重時致命。安全底材包括椰子纖維磚、廚房紙巾、磁磚或岩板。 | §4.1.2 爬蟲缸佈置（底材選擇）、§5.5.2 生病題（腸阻塞說明） |
| 脫皮需要濕躲避屋輔助 | 守宮定期蛻皮，若環境過乾或缺乏濕躲避屋（moist hide），脫皮不完全會殘留在趾端、眼周，導致血液循環受阻，嚴重時趾端壞死。 | §4.1.2 爬蟲缸佈置（濕躲避屋）、§5.3 D-3 脫皮情境 |

## 四、領養前準備階段

### 4.0 家庭與居住確認（固定格式，不需更動）

> 📌 **§4.0 的同住者共識（卡 A / B / C）固定不動**，物種相關詞調整如下：
> 守宮版將「氣味、毛髮、作息」替換為「**爬蟲缸器材聲音（加熱片運作聲）、活體昆蟲飼料、夜行性作息**」。

**租屋提醒**（前兩點固定，第三點物種特定）：
- 房東是否已**書面**同意飼養？口頭同意在換房東或房客搬遷時可能無法保障。
- 台灣「可寵租屋」比例較低，若未來因故需要搬家，找尋寵物友善住宅的難度相對較高——請提前評估。
- 守宮雖無明顯叫聲，但**活體昆蟲飼料**（蟋蟀等）有聲音與氣味；爬蟲缸的加熱設備需要穩定電力，請確認租屋電力是否充足、是否允許放置爬蟲缸。

**自有住宅提醒**（第一點固定，第二、三點物種特定）：
- 社區或公寓管委會可能有**寵物相關規定**（如禁止進出公共空間、寵物體重上限、須繫牽繩等），請事先確認，避免日後糾紛。
- 守宮缸需要**持續的環境溫度維持**，若住家冬天極冷或夏天極熱，需評估加熱或空調設備是否足以維持安全溫度範圍（環境溫度不低於 18°C）。
- 守宮逃脫後難以尋找，且若誤入牆縫或管道恐難救援——請確認飼養空間的**防逃措施**（爬蟲缸蓋緊固，活動空間無縫隙）。

#### 5.3.2 每日健康巡視（GeckoHealthInspectionActivity）

> **定位**：玩家在爬蟲缸內依序點擊五個巡視點，每個點擊後顯示今日狀態（`displayState` 隨機分配 `normal` / `warning`），並進行判斷題。全部巡視點確認完成後，顯示三段式完成畫面。**核心訊息**：守宮善於隱藏不適，每日固定巡視是飼主主動發現健康問題的唯一方式。

**一局流程**：
```
步驟 1：點擊溫度計圖示 → 顯示暖側 / 涼側溫度讀數 → 判斷是否在安全範圍（判斷題）
步驟 2：點擊水碟 → 確認飲水並補充新鮮水（點擊確認）
步驟 3：點擊底材排泄角落 → 顯示排泄狀態與分量 → 判斷是否有需注意的異常（判斷題）
步驟 4：點擊守宮本體 → 依序觀察 4 個部位（眼睛、尾巴、皮膚、趾端），各進行判斷題
全部完成 → 進入三段式完成畫面
```

**畫面與操作方式**：

---

**步驟 1 — 溫度計（暖側 / 涼側）**

顯示爬蟲缸側視圖，暖側角落有一個溫度計圖示，涼側角落有另一個溫度計圖示。玩家**點擊溫度計圖示**，彈出兩個溫度讀數卡片：暖側溫度與涼側溫度。

`displayState` 當局隨機為 `in-range`（暖側 28–32°C，涼側 22–25°C）或 `out-of-range`（暖側或涼側溫度偏離正常值）。

**判斷選項**：

| 選項 | 選項文字 | 適用狀態 |
|---|---|---|
| A | 溫度正常，暖涼兩側都在安全範圍 | in-range 正確 / out-of-range 錯誤 |
| B | 溫度有問題，需要調整 | in-range 錯誤 / out-of-range 正確 |

**回饋（四種組合）**：

- **in-range，選 A（正確）**：✅ 正確！今天的溫度梯度良好——暖側 28–32°C、涼側 22–25°C，{petName} 可以自由選擇牠舒適的溫度區域。繼續每天確認。

   > **異常對照提示（in-range＋正確時固定顯示）**：「⚠️ 溫度超過 35°C 可能引發熱衰竭；低於 18°C 守宮消化與免疫功能都會受影響，請立刻調整加熱設備。」
- **in-range，選 B（錯誤）**：其實今天的溫度是正常的——暖側與涼側都在安全範圍內。守宮是外溫動物，需要同時提供暖側（28–32°C）與涼側（22–25°C），讓牠自行選擇最舒適的位置。
- **out-of-range，選 B（正確）**：✅ 正確！你注意到了溫度異常——守宮無法自行調節體溫，環境溫度偏低時消化與免疫功能都會受影響，請立刻檢查加熱設備並調整。
- **out-of-range，選 A（錯誤）**：仔細再看——今天的溫度讀數有偏差，不能視為正常。守宮靠環境溫度維持代謝，溫度不對的環境會讓牠無法消化食物，甚至影響免疫力，請盡快調整加熱設備。

**知識來源**：G4（`各類群飼養細則.md`「守宮篇─溫度設定」）

---

**步驟 2 — 水碟**

### 6.7 額外注意事項——非主線情境提醒

---

**若有計畫繁殖——守宮的繁殖與卵的照顧**

守宮繁殖需要額外的設備與知識，**不建議新手在未充分準備下嘗試**。雌守宮即使未交配，也可能產下無精卵；若卵無法順利排出（卵阻塞），需就醫甚至手術。繁殖前應先了解孵蛋設備（孵卵器、孵化介質）、幼體的分缸管理，以及如何安置多隻幼守宮——**每隻幼守宮都需要獨立的缸具**。

**知識來源**：G3（`爬蟲類-通則/爬蟲類-健康醫療與相處.md`「繁殖相關健康問題」）；W1（「常見健康問題─卵阻塞」）

---

**沙門氏菌——與守宮互動後的手部衛生**

爬蟲類（包含守宮）的腸道中可能帶有沙門氏菌，**接觸後不洗手可能透過口腔途徑感染**，對嬰幼兒、孕婦與免疫力較弱者尤其危險。每次觸碰守宮、清理缸具或排泄物後，請立即用肥皂洗手。**5 歲以下兒童應在大人監督下接觸守宮，並立即洗手**。

**知識來源**：G3（`爬蟲類-通則/爬蟲類-健康醫療與相處.md`「沙門氏菌注意事項」）

---

**守宮是獨居動物——不要同缸飼養**

雄性守宮相遇必然發生激烈打鬥，雌性同缸也有競爭行為與壓力風險。即使看起來相安無事，**弱勢個體可能長期在壓力下飲食不穩、免疫力下降**。若想同時飼養多隻守宮，每隻必須有**完全獨立的缸具**。

**知識來源**：G2（`爬蟲類-通則/爬蟲類-挑選與飼主自我評估.md`「物種評估─獨居性」）；G4（`爬蟲類-通則/爬蟲類-各類群飼養細則.md`「守宮篇─社交」）

---

**若家中同時飼養貓狗——爬蟲缸的隔離**

守宮是小型爬蟲，即使沒有被直接攻擊，貓狗在爬蟲缸周圍持續出現本身就是掠食者壓力訊號。長期暴露在這種壓力下，守宮可能出現慢性免疫力下降、拒食或行為退縮。**請確保爬蟲缸放置在貓狗無法進入或靠近的空間**，或使用附鎖扣的加固型缸蓋，防止貓狗開蓋或拍打缸壁。

**知識來源**：G2（`爬蟲類-通則/爬蟲類-挑選與飼主自我評估.md`「物種共存評估」）
