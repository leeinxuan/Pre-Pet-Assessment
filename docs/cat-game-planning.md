## 一、企劃概述

### 1.1 目標

貓版飼養前評估遊戲遵循相同的 8 步驟主流程與共用元件架構，所有貓咪專屬內容集中在 `app/data/species/cat/` 設定檔。本文件記錄完整遊戲流程，包含：品種的考驗設計邏輯、各情境題目與回饋文字、日常照護互動設計，以及旅程設定資料。

### 1.2 貓咪的核心照護差異（與犬類相比）

| 差異點 | 說明 | 遊戲設計重點 |
|---|---|---|
| 社交需求較低但仍需互動 | 貓咪獨立性強，但完全忽視仍可能造成焦慮或行為問題 | 日常互動情境 |
| 獵捕本能強 | 所有貓咪均保有搜索→追逐→撲抓→收尾的完整獵捕循環 | 夜晚精力情境 |
| 抓磨需求是天性 | 抓磨是自然行為，需提供替代品引導，不應用懲罰阻止 | 抓沙發情境 |
| 隱藏病徵能力強 | 貓咪天性隱藏疼痛與不適，需主動定期健檢與每日觀察 | 就醫情境 |
| 室內外管理 | 室外貓面臨車禍、感染、打架等風險；完全室內飼養需豐富化 | 室內外選擇情境 |
| 品種健康差異 | 英國短毛貓有HCM遺傳風險；米克斯貓則需了解個體背景 | 品種的考驗 |

| 抓板或跳台 | 必要 |
| 可退避的安全躲藏空間 | 必要 |
| 日常休息空間 | 必要 |

#### 4.1.2 危險物品（應移除）

| 顯示名稱 | 危險原因 |
|---|---|
| 線狀物 | 貓咪可能誤食線狀物，造成腸胃道阻塞 |
| 有毒植物 | 部分室內植物對貓有毒，貓可能啃咬 |
| 溶劑產品（清潔劑等） | 揮發性或接觸性毒性可能傷害貓咪 |

#### 5.3.2 貓砂盆救援隊（LitterInspectionActivity）

> **互動機制**（貓版物種專屬日常遊戲，對應犬版「散步」）：玩家進入貓砂盆場景，將砂盆中的廢棄物（尿團、便便）拖曳至垃圾桶，完成清潔。設計核心是讓玩家感受「每天的例行清理」——貓砂盆清潔是維持貓咪健康與觀察排泄狀況的重要日常任務。

**場景標題**：貓砂盆救援隊

**互動流程**：
- 砂盆中出現廢棄物（尿團、便便），玩家逐一拖曳至垃圾桶
- 完成所有廢棄物清除後算完成一輪
- 需完成 targetStamps = **3** 輪

**廢棄物設定（wasteItems）**：

| id | 種類 | 顯示名稱 |
|---|---|---|
| `urine-1` | 尿 | 第 1 個尿團 |

### 5.4 品種的考驗（BreedChallengeActivity）

---

#### 英國短毛貓（british-shorthair）

##### 考驗 1：英短的嗜食本性

**挑戰標題**：英短的貪食本性

**情境**：英國短毛貓食慾旺盛，但天生活動量偏低。你打算怎麼幫牠維持健康體重？

**topic**：飲食與體重管理

**問題**：以下哪個做法最能幫助英短維持健康體重？

| 選項文字 | 正確性 | explanation | suggestion |
|---|---|---|---|

## 六、照護評估報告（Step 7：CareReport）

### 6.1 每日照護時間

**每日約需安排 45 分鐘以上**

包含餵食與換水、貓砂盆與環境清潔、互動陪伴，以及觀察食慾、飲水與排泄狀況。時間會依貓咪年齡、健康狀況、毛長與個性而有所變動。

### 6.2 每日照護明細

| 照護項目 | 每日時間 |
|---|---|
| 餵食與換水 | 約 10～15 分鐘 |
| 貓砂盆與環境巡視 | 約 5～10 分鐘 |
| 陪伴與互動 | 約 15～30 分鐘 |
| 清潔與狀況觀察 | 約 5～10 分鐘 |

### 6.3 報告清單（checklistGroups）

**每日照顧**：固定餵食、提供乾淨飲水、每日巡視並清除排泄物、維持足夠且乾淨的貓砂、留意排泄異常（記錄後儘速聯絡獸醫）、安排安全陪玩、保留安靜休息與躲藏處

**家中環境**：門窗與紗窗穩固、可退避的安全躲藏空間、日常休息空間、貓砂盆與貓砂、食盆與水碗、抓板或跳台、線狀物與有毒植物與溶劑產品收好

**外出與接回**：身分證、飼養文件、外出籠、尿墊、水碗、飲水與清潔用品

### 6.4 情境應對說明（handlingRows）

| 情境 | 應對方式 |
|---|---|
| 忙碌或離家 | 交接食水、砂盆、環境巡視與狀況回報 |
| 食慾、飲水或尿便異常 | 記錄變化並儘速聯絡獸醫 |
| 每週清洗貓砂盆 | 先放置備用砂盆，清洗後完全晾乾再放回 |

| 居家安全 | 收好線狀物、有毒植物、人用藥與清潔劑 |
| 高齡階段 | 調整低入口砂盆、階梯式跳台與溫暖休息處 |

**緊急費用說明**：這筆金額用來模擬一次突發就醫時的現金緩衝，不代表能支付完整治療，也不是貓咪一生的醫療費。

## 十、實作注意事項

1. **日常照護互動**：`cat-daily-inspection` 類型為 `"daily-inspection"`，對應 `LitterInspectionActivity` 元件（`catLitterRescueConfig` 設定）。目前 `enableWeeklyWash` 與 `enableAbnormalObservation` 均為 `false`，週清洗與異常觀察功能尚未啟用。

2. **catScenarioCorrectFeedback**：單選情境的做得很好頁面使用 `catScenarioCorrectFeedback` 物件（`cat-arrival-adjustment`、`cat-illness-vet`、`cat-growing-old`）；`cat-busy-care` 無獨立 feedback 條目，做得很好頁面直接顯示正確選項的 explanation 與 suggestion。

3. **多選情境結構**：複選情境（`cat-night-energy-care`、`cat-scratching-care`、`cat-indoor-outdoor-care`）使用 `correctSummary`（條列正確做法）與 `learningPoints`（小知識）顯示做得很好頁面。

4. **品種考驗 fallback**：`getCatBreedChallengeScenarios()` 在 `breedId` 不存在時自動回傳 `"mixed-cat"` 題目，mixed-cat 設計應具普遍代表性。

5. **費用清單確認**：`sick-vet-care`、`cat-senior-room`、`senior-checkup` 需確認已在 `expenses.ts` 中定義，並核對金額與分類欄位。

6. **建置驗證**：程式碼更新後依序執行：
   ```
   corepack pnpm run build
   corepack pnpm test
   corepack pnpm run lint
   ```
