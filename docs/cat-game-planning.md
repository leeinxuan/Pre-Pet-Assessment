# 貓咪飼養前評估遊戲｜流程與內容企劃（MVP）

> 版本：v0.1｜對象：準備飼養貓咪者｜內容狀態：供團隊／專家審稿
>
> 本企劃以既有犬版的主流程為骨架；貓咪內容只採用團隊 Obsidian 知識庫已整理的資料。醫療與法規內容只引導「觀察、記錄、聯絡專業人員」，不提供診斷、用藥或固定醫療門檻。

## 1. 產品目標與原則

### 目標

讓準飼主在帶貓回家前，先透過模擬做出照護選擇，理解日常清潔、居家安全、適應、照護備援與長期責任，而非只完成用品購物清單。

### 保留犬版的整體節奏

```text
選擇寵物 → 飼養前準備 → 飼養生活 → 照顧準備總覽 → 取得寵物
                         └ 接回家 → 日常照護 → 品種的考驗 → 生活變化
```

### 貓咪版三項內容原則

1. **橘貓、虎斑貓作為選擇卡片，而非生物學品種宣稱。** UI 可沿用「選擇品種」欄位以維持犬版一致，但卡片內應標示「外觀類型」。不可將毛色／花紋寫成固定個性或疾病傾向。
2. **以個體與情境做判斷。** 躲藏、食慾下降、噴尿、理毛或活動改變可能與壓力或疾病有關；遊戲不得把單一現象說成唯一原因。
3. **醫療與法規可追溯、可更新。** 每個關卡保留 Obsidian note 與 source ID；法律義務以「依現行主管機關規定確認」呈現。

| 流程區段 | 側欄名稱 | 玩家完成的事 | 通關結果 |
|---|---|---|---|
| 01 | 選擇寵物 | 選貓、選外觀類型、命名、填既有飼養經驗 | 建立這次旅程的貓咪名稱與分支 |
| 02 | 飼養前準備 | 布置安全生活空間、準備接回用品 | 建立安全房與外出籠準備 |

## 3. 選擇寵物

### 3.1 選擇物種

- 卡片：`貓`。
- 行為：選擇後進入「選擇品種」。

### 3.2 選擇品種（畫面副標：外觀類型）

| ID | 顯示名稱 | 卡片說明 | 分支用途 |
|---|---|---|---|
| `orange-cat` | 橘貓 | 外觀類型：橘色被毛。每一隻貓的年齡、過往經驗、健康與個性都不同。 | 飲食與家庭餵食紀錄題 |
| `tabby-cat` | 虎斑貓 | 外觀類型：虎斑花紋。每一隻貓的年齡、過往經驗、健康與個性都不同。 | 環境豐富化與安全陪玩題 |

> 禁止文案：橘貓「天生愛吃／親人」、虎斑貓「一定活潑／愛搗蛋」。目前的 Obsidian 貓篇沒有可支持此類歸因的品種資料。

### 3.3 命名與過往經驗

- 命名畫面沿用犬版。
- 問題改為「你以前有和貓咪一起生活過嗎？」；若有，填寫以前貓咪的外觀類型與名字。
- 過場文案：熟悉以前的貓，不代表新貓會以相同速度適應；需依這一隻貓的反應、健康與生活史調整。

## 4. 飼養前準備

### 4.1 關卡 A：布置貓咪安全房

**操作方式**：拖曳用品到房間；點擊危險物後選擇「收好／隔離／加裝防護」。必備品全數完成且高風險危害均處理後才可前往下一關。

| 類別 | 物件／任務 | 完成時回饋 | 未完成風險 |
|---|---|---|---|
| 休息 | 安全躲藏／休息空間（例如紙箱、遮蔽貓窩或其他合適空間） | 「保留可自行選擇的躲藏處，讓牠有退路。」 | 新環境中沒有能降低刺激的安全角落 |
| 排泄 | 合適尺寸貓砂盆，放在安靜固定處 | 「位置安靜、不被打擾，並和食水保持距離。」 | 氣味、干擾或盆太小可能降低使用意願 |
| 飲食 | 食盆與乾淨水碗，彼此與貓砂分區 | 「食水與排泄分開，較符合貓咪對氣味的敏感。」 | 食水受貓砂氣味干擾 |
| 活動 | 抓板、穩固跳台、安全實體玩具 | 「提供抓磨、垂直活動與可完成捕捉的遊戲。」 | 用家具或手腳取代合適活動出口 |
| 防墜 | 窗戶、紗窗、陽台的防逃防墜措施 | 「確認不能被推開、沒有過大縫隙。」 | 墜樓或逃脫 |
| 危害 | 百合／其他有毒植物、人類藥品、線狀異物、精油與薰香、清潔劑 | 「已移出可接觸範圍。」 | 誤食、吸入或異物傷害 |

**關卡結算提醒**：安全房不等於長期籠飼；應提供可活動、躲藏與垂直空間。

### 4.2 關卡 B：出發前準備

**操作方式**：從用品架選取並放入車內／接回包。選到錯誤物品時顯示原因，但可重新選擇。

| 用品 | 是否必備 | 回饋 |
|---|---:|---|
| 尺寸合適、通風且結構穩固的外出籠 | 是 | 「接回與就醫都以外出籠作為安全運輸空間。」（O3） |
| 身分證與領養文件 | 是 | 「依領養單位要求準備身分與認養文件；此為認養流程作業需求，非 O1–O7 貓照護指南的通用飼養主張。」 |
| 既有飲食、疫苗、除蚤驅蟲與健康資訊 | 是，但依取得來源適用 | 「從收容所或特定寵物業取得時，應取得這些資訊；先掌握既有飲食與健康狀況。」（O3） |
| 乾淨飲水 | 是 | 「移動與外出時維持足夠飲水。」（O3） |
| 就近醫療資源與緊急聯絡資訊 | 是 | 「迎接前先找到可就診的動物醫院；實作上以手機聯絡卡呈現。」（O2） |

**不放入出發頁的物件**：安全躲藏／休息空間、貓砂盆與貓砂屬於「布置生活空間」關卡；依 O3，它們應在安全房中先準備好，而不是當成車內攜帶物。身分證與領養文件保留為本遊戲的認養流程作業必備物，實際內容仍依各收容／認養單位要求確認。

**來源對照**：O3＝`貓-居家環境與安全防護.md` 第 31–35 行（接回前健康／飲食資訊與安全房）、第 136–145 行（飲水、外出籠與尺寸）；O2＝`貓-飼養前評估.md` 第 47–51 行（就近醫療資源）。

## 5. 飼養生活

### 5.1 接回家（含餵食）

#### 題目 1：第一次來到新家

- **題幹**：到家後，「{petName}」待在外出籠裡不願出來。家人擔心牠是不是不喜歡新家。
- **操作**：單選處置方式；只有一個完整正確處置可進入正確回饋與第一餐。

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 把牠抱出籠，讓牠快點認識新家 | 錯誤 | 強迫離開外出籠可能讓貓更緊張，也可能引發防衛或躲藏。 |
| 關好門窗，放好食水與砂盆，打開外出籠讓牠自行探索 | 正確 | 保留退路並降低刺激，能幫助貓建立安全感。 |
| 請家人圍過來叫牠，讓牠知道大家都歡迎牠 | 錯誤 | 多人靠近、聲音與注視會提高剛到家的壓力。 |
| 一進門就打開全屋，讓牠一次探索所有房間 | 錯誤 | 一次面對整個陌生環境可能增加壓力，也讓牠難以找到可退回的地方。 |

#### 題目 2：幫牠準備第一餐

- **題幹**：`{petName}` 剛到新家，還有些不安。先幫牠準備合適的主食與乾淨飲水，讓牠慢慢安心下來。
- **操作方式**：完全沿用犬版「第一餐」互動。左側用品架顯示正確食物、乾淨水，以及錯誤食物；玩家將正確食物與水點選／拖曳至食盆、水碗。錯誤食物可點擊查看警示，但不能完成餐點。兩個正確項目都完成才可繼續。

| 物品 | 分類 | 點擊後回饋 |
|---|---|---|
| 熟悉且符合個體營養需求的貓主食 | 正確 | 「先維持熟悉食物；若日後轉換新食物，採漸進方式。」 |
| 乾淨飲水 | 正確 | 「隨時提供乾淨水；不以灌水方式增加攝水。」 |
| 洋蔥／蒜調味的剩菜 | 錯誤 | 「人類調味食物不適合貓咪，洋蔥、青蔥與大蒜尤其應避免。」 |
| 巧克力或含咖啡因點心 | 錯誤 | 「這類人類食品可能對貓造成健康危害，不可當作正餐或安撫食物。」 |
| 含木糖醇口香糖或人用藥品 | 錯誤 | 「人用藥品與含木糖醇產品都必須收好；不要自行讓貓食用。」 |

**完成回饋**：`「第一餐準備好了。合適主食與乾淨飲水是每天照顧的開始；接下來持續觀察牠的進食、飲水與排泄。」`

### 5.2 日常照護

#### 日常情境選擇（對應犬版的吠叫／亂咬／如廁）

**目前網頁題型**：三題皆為複選；每題要選出三個正確做法，避開一個錯誤做法後才能繼續。

##### 題目 1：晚上還很有精神

- **題幹**：晚上你準備休息時，`{petName}` 開始在家裡奔跑、叫喚，還會撲向晃動的手腳。你會怎麼安排牠的精力與互動？

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 用雷射筆讓牠一直追光點，累了自然會睡 | 錯誤 | 不應使用雷射筆；它可能造成傷害，也沒有能讓貓實際捕捉的目標。 |
| 提供安全玩具或益智漏食玩具，讓牠有合適的活動出口 | 正確 | 安全玩具能分散精力，降低無聊造成的撲咬或叫喚。 |
| 睡前安排短段逗貓棒遊戲，讓牠追逐、捕捉後慢慢收尾 | 正確 | 規律互動能滿足獵捕與活動需求，建立夜間節奏。 |
| 不用手腳直接逗弄，改用玩具保持安全距離 | 正確 | 讓牠追玩具而不是追人的手腳。 |

##### 題目 2：抓沙發不是故意搗蛋

- **題幹**：`{petName}` 最近比較常抓沙發、窗簾和衣櫃邊角，家人擔心家具一直被破壞。你會怎麼引導牠？

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 準備穩固抓板或抓柱，放在牠常抓或常經過的位置 | 正確 | 抓板提供自然抓磨出口；位置合適才容易替代家具。 |
| 為了保護家具，替牠去爪、磨牙或剃鬍鬚 | 錯誤 | 除平時清潔與修剪指甲外，不應去爪、磨牙或剃鬍鬚；這些做法不能取代抓磨環境。 |
| 在抓對地方時給鼓勵，並用家具保護或動線調整降低抓錯機會 | 正確 | 替代物搭配環境管理，比只要求牠不要抓更容易穩定。 |
| 整理窗簾、衣櫃與高處路線，確認門窗和紗窗穩固 | 正確 | 抓磨與攀爬可能牽涉安全風險，先整理環境能避免受傷或逃脫。 |

##### 題目 3：牠不想出門

- **題幹**：家人覺得貓咪也應該像散步一樣出門走走，但牠看到外出籠就緊張後退。你會怎麼安排？

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 看見牠緊張就先停止，不強迫牠出門散步 | 正確 | 尊重壓力訊號能減少恐懼累積。 |
| 直接抱牠出門，多去幾次就會習慣 | 錯誤 | 強迫外出可能增加恐懼與逃脫風險。 |
| 在室內安排跳台、抓板、安全玩具與陪玩時間 | 正確 | 室內豐富化能滿足活動與互動需求。 |
| 把外出籠放在日常可接觸的位置，慢慢練習需要外出時的安全移動 | 正確 | 平時讓外出籠變成可接受的物品，有助就醫或移動。 |

#### 貓砂盆清潔（對應犬版散步互動）

**定位**：這是犬版「散步互動」的唯一對應活動，名稱為 **「貓砂盆救援隊」**。日常照護的互動只保留貓砂盆清潔；食水、陪玩與健康紀錄仍可在其他題目或總覽中呈現，但不放進此小遊戲。

**設計目標**：讓玩家以短時間、低壓力的操作記住三個重點：每日清除排泄物 2–3 次、砂量要足以掩埋、每週清洗時要使用備用盆並完全晾乾。貓咪「聞 → 挖掘 → 轉圈 → 排泄 → 掩埋」的動畫只作為情境提示，不要求玩家干預貓咪上廁所。

**一局流程（約 60–90 秒）**：

```text
選擇本次巡視時段（早／晚）
  → 用貓砂鏟找出並鏟除尿團與糞便
  → 把排泄物放進密封清潔桶
  → 檢查砂量，缺少時補到可掩埋的程度
  → 遇到「每週清洗日」：換上備用盆，清洗原盆並選擇完全晾乾
  → 顯示本日第 1／2／3 次清潔印章與完成回饋
```

**畫面與操作方式**：

1. 畫面中央是一個尺寸足以讓貓轉身的開放式貓砂盆；角落有時段印章、清潔桶、補砂袋與備用盆。
2. 玩家拖曳貓砂鏟掃過可見的尿團與糞便，鏟到後會出現「聞、挖、轉圈、掩埋」中的對應足跡提示，直到砂面乾淨。
3. 砂面過淺時會露出「無法順利掩埋」提示；玩家點擊補砂袋補足。砂量足夠後，貓咪會完成掩埋動畫。
4. 每三局隨機出現一次「每週清洗日」：玩家先點選備用盆，再把原盆送去清洗；若直接把濕盆放回去，顯示「需完全晾乾後再使用」並重試。
5. 每次完成得到一枚巡視印章；當天集滿 2–3 枚即顯示「今天的排泄物已定期清除」。不把次數做成漏一次就失敗的壓力機制。

**通關條件**：清除全部可見排泄物、砂量足以掩埋；每週清洗事件中正確使用備用盆並完全晾乾原盆。

**事件卡與回饋**：

| 事件選項 | 結果 | 回饋方向 |
|---|---|---|
| 清除排泄物後發現砂太淺，補足到能掩埋的程度 | 正確 | 足夠砂量能讓貓完成掩埋動作。 |
| 想用濃香芳香劑掩蓋砂盆味道 | 錯誤 | 氣味可能讓貓排斥；應清除排泄物並定期清洗。 |
| 每週清洗時先換上備用盆，再讓原盆完全晾乾 | 正確 | 清洗期間仍保有可用砂盆，原盆完全乾燥後再使用。 |
| 清洗後直接把還濕的砂盆放回去 | 錯誤 | 清洗後應完全晾乾；可先以備用盆替換。 |
| 發現排泄困難或顯著改變，先記錄時間與現象並聯絡獸醫 | 正確 | 不能只當作行為問題；紀錄不取代急症處置。 |
| 牠沒上對地方就責罵 | 錯誤 | 先檢查砂盆、環境與健康可能性，不處罰。 |

**完成回饋**：`「砂盆已清潔，砂量也足夠。持續在固定、安靜的位置定期巡視；若發現排泄困難或明顯改變，請聯繫獸醫。」`

### 5.3 品種的考驗（外觀類型分支）

**目前網頁題型**：依選擇的橘貓／虎斑貓，連續完成三題單選題；每題有一個正確做法與三個錯誤做法。以下為目前實作題庫的題目與正確作法。

| 外觀類型 | 題目 | 題幹重點 | 正確作法 |
|---|---|---|---|
| 橘貓 | 撒嬌也需要合適的遊戲 | 主動討摸、討玩或無聊時討食 | 每天安排逗貓棒等互動遊戲，不用手腳逗弄，並提供安全玩具與益智漏食玩具。 |
| 橘貓 | 舒服生活也需要安全高處 | 想讓貓不無聊又能安全活動 | 提供穩固貓跳台或層架、安靜休息處，並確認門窗與紗窗穩固。 |

### 5.4 生活變化

#### 題目 1：臨時晚歸，誰來接手？

- **題幹**：今天臨時需要晚歸，`{petName}` 仍需要食水確認、貓砂盆清理、環境巡視、適當陪玩與狀況觀察。
- **來源與界線**：O2 支持持續處理食物、飲水、貓砂、環境安全與互動，並在出遊、生病或生活變動時預先安排代養人。題目不設定貓咪可獨處的固定時數，也不把犬隻的獨處需求直接套用到貓身上。
- **操作方式**：與犬版「疲憊忙碌的日子」完全同構。玩家先選擇處置；選到「請同住家人或朋友協助」後，進入協助者確認流程：輸入名字，逐題確認對方的時間、意願、照護知識與緊急聯絡方式。任何一項答「否」都要回到尋找合適備援。

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 出門前多放一些食物和水，回家後再一起處理砂盆和陪玩 | 錯誤 | 食物和水不能取代砂盆清理、環境巡視、陪玩與狀況觀察。 |
| 請可信任、了解照護需求的家人或朋友協助 | 正確 | 交接食水、砂盆、環境巡視、陪玩與狀況觀察，才能維持規律照護。 |
| 貓咪本來就很獨立，晚一點回家再看就好 | 錯誤 | 獨立不代表不需要日常照護與安全巡視。 |
| 只請人倒飼料，不用交代砂盆、陪玩或觀察狀況 | 錯誤 | 只補食物會漏掉砂盆、飲水、環境安全與行為變化。 |

#### 題目 2：牠突然變得不太一樣

- **題幹**：`{petName}` 今天吃得比平常少、躲得更久，貓砂盆裡的尿團也明顯減少。你無法確定是壓力還是身體不舒服，但這些改變一起出現了。此刻要先怎麼做？
- **操作**：四選一。正確答案整合觀察紀錄、就醫準備與聯繫獸醫；其他選項分別是等待、只問朋友、或自行用藥等不完整／有風險做法。
- **來源與界線**：O7 指出突然不吃、飲水或排泄顯著改變、反覆嘔吐腹瀉、呼吸異常、明顯疼痛、持續躲藏或活動力下降時，應保留資訊並聯繫獸醫；紀錄不能取代或延後急症處置。壓力與疾病可能有相似表現，遊戲不做疾病診斷。

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 記下食慾、飲水、尿便、活動與躲藏的前後變化，準備外出籠與可用資料，並立即聯繫獸醫 | 正確 | 多項變化一起出現時，完整紀錄、就醫準備與聯繫獸醫要一起做；紀錄不能延後急症處置。 |
| 先當作只是心情不好，等幾天看看會不會自己恢復 | 錯誤 | 多項改變一起出現時，不應自行歸因或延後聯繫獸醫。 |
| 只拍一張照片傳給有養貓的朋友，等對方回覆後再決定 | 錯誤 | 朋友經驗無法取代獸醫判斷；影像可保留，但仍應主動聯繫獸醫。 |
| 先用家裡的人用藥或剩下的藥物試試看 | 錯誤 | 未經獸醫指示的藥物可能對貓有害，也會干擾後續判斷。 |

#### 題目 3：貓咪慢慢變老

- **題幹**：11 歲的 `{petName}` 最近跳上跳下變慢，進出原本的砂盆也比較猶豫。你想讓牠繼續安全地活動、上廁所與休息，同時建立可長期追蹤的照護節奏。需要怎麼調整？
- **操作**：四選一。唯一正解把如廁、活動、休息與健康追蹤整合為同一套照護方案；其餘三項都是只做一部分或增加負擔的做法。
- **來源與界線**：O6 指出貓咪 7 歲進入熟齡期、11 歲以上進入高齡期；建議每半年健康檢查、每週搭配外出籠量體重，並調整砂盆、地墊、階梯式設施與保暖。慢性疾病風險只作健康追蹤與就醫準備，不用來診斷。

| 選項 | 結果 | 回饋方向 |
|---|---|---|
| 增設高度適中的砂盆與地墊、改成階梯式設施並準備保暖休息處；每半年健檢、每週量體重並記錄日常變化 | 正確 | 如廁、活動、休息與健康追蹤一起調整，才能更完整回應高齡生活需求。 |
| 只買保健品，維持原有高跳台與砂盆，等明顯不舒服再處理 | 錯誤 | 保健品不能取代環境調整、健康追蹤與獸醫評估。 |
| 只多放一張軟墊，其他生活動線與砂盆都先不改 | 錯誤 | 休息處重要，但不足以處理如廁、跳躍與健康追蹤等需求。 |
| 維持原本高跳台，讓牠多跳一點就會慢慢適應 | 錯誤 | 忽略行動變化可能增加關節負擔，也可能讓牠減少使用生活空間。 |

## 6. 照顧準備總覽（與犬版同構）

報告沿用犬版的組成、判定方式與操作：**整體準備程度 → 已準備 → 需要再確認 → 和家人討論 → 下一步行動 → 情境回顧 → 照顧承諾 → 個人資料補充 → 取得寵物**。不以單一分數判定是否可以養貓。

### 6.1 與犬版相同的資料輸入與計算

| 犬版構成 | 貓版對應 |
|---|---|
| 必要用品完成度、危害物完成度、後車廂通關 | 貓安全房必要用品完成度、貓危害物完成度、出發前必備用品通關 |
| 情境第一次答對數、生活練習完成度 | 貓咪情境第一次答對數、第一餐與貓砂盆救援隊完成度 |
| 活動空間、飼養原因、租屋／同住者共識 | 保留相同欄位；活動空間文字改為「貓咪主要活動、躲藏與垂直空間」 |
| 強訊號計算三種準備程度 | 保留相同三段：`已具備多項準備`／`有部分條件需要先確認`／`建議先完成準備事項` |

### 6.2 報告清單內容替換

| 區塊 | 貓版顯示條件／文案 |
|---|---|
| 已準備 | 「必要用品與安全生活空間已完成」；「居家危險物已完成收納與防護」；「接貓用品、文件與安全運輸已通過檢查」；「已完成到家第一餐與貓砂盆救援隊」；「已規劃貓咪的主要活動、躲藏與垂直空間」 |
| 需要再確認 | 「必要用品完成度 {n}%」；「仍有居家危險物需要防護」；「接貓用品尚未通過檢查」；「尚未填寫貓咪預計活動空間」；「尚未填寫飼養原因」；「情境需要再確認：{topic}」 |
| 和家人討論 | 保留「所有同住者是否知情並同意飼養」、「租屋規定與房東書面同意」；增加提示「誰在忙碌、出差或突發狀況時接手食水、砂盆、環境巡視與互動」。 |
| 下一步行動 | 「帶著來源、年齡、已知健康與飲食紀錄問題詢問獸醫或領養單位」；「和同住家人確認安全房、門窗防護、日常清潔與備援分工」。 |
| 情境回顧 | 首次未答對或協助者確認不完整的題目，開啟知識卡；「臨時晚歸，誰來接手？」固定顯示：需確認協助者是否真的有時間、能力與意願照顧貓咪。 |
| 照顧承諾 | 保留犬版勾選承諾與解鎖「取得寵物」的機制；文字換為能持續提供食水、砂盆清理、安全環境、互動、醫療與照護備援。 |
