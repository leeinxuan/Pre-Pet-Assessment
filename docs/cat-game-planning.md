## 一、企劃概述

### 1.1 目標

讓準飼主在帶貓回家前，先透過模擬做出照護選擇，理解日常清潔、居家安全、適應、照護備援與長期責任，而非只完成用品購物清單。

在既有的「犬版」飼養前評估遊戲流程之上，新增**貓版**內容。貓版遵循相同的主流程與共用元件架構，所有貓咪專屬內容集中在 `app/data/species/cat/` 設定檔，不重複複製頁面元件、不在元件內散落 `species === "cat"` 條件判斷。

### 1.2 貓的核心照護差異（與犬相比）

| 差異點 | 說明 | 遊戲設計重點 |
|---|---|---|
| 砂盆潔癖 | 貓對砂盆乾淨度極敏感，積存的排泄物可能讓牠改用其他地方排泄 | 貓砂盆清潔小遊戲設計 |
| 隱藏不適 | 貓天生隱藏疼痛，24 小時未進食即需立刻關注 | 日常觀察警訊與備援確認設計 |
| 垂直空間需求 | 需要可攀爬、躲藏的垂直環境才能維持安全感 | 安全房布置場景 |
| 百合等劇毒植物 | 百合科植物對貓有致命毒性，連花粉都危險 | 危害物移除場景強化 |
| 室內飼養為主 | 建議完全室內飼養，戶外有逃脫、感染、墜樓等風險 | 防墜防逃設計關卡 |
| 獨立但仍需日常互動 | 貓雖獨立，仍需每日陪玩、觀察與環境巡視 | 備援計畫強調每日到訪必要性 |

### 1.3 內容三項原則

1. **外觀類型，而非生物學品種宣稱。** UI 可沿用「選擇品種」欄位，但卡片內應標示「外觀類型」。不可將毛色／花紋寫成固定個性或疾病傾向。
2. **以個體與情境做判斷。** 躲藏、食慾下降、噴尿、理毛或活動改變可能與壓力或疾病有關；遊戲不得把單一現象說成唯一原因。
3. **醫療與法規可追溯、可更新。** 每個關卡保留 Obsidian note 與 source ID；法律義務以「依現行主管機關規定確認」呈現。

## 四、飼養前準備階段

### 4.1 安全房布置（RoomSetupActivity）

> **互動機制**：拖曳用品到房間；點擊危險物後選擇「收好／隔離／加裝防護」。必備品全數完成且高風險危害均處理後才可前往下一關。

必備用品（對應 preparation.ts `catRoomItems`，全部 `required: true`）：

| ID | 標籤 | need | purpose（放置回饋） |
|---|---|---|---|
| `cat-safe-window` | 窗戶防護網 | 安全 | 先確認門窗、紗窗與陽台防護穩固，避免貓咪逃脫或墜落。 |
| `cat-hide-box` | 可退避的安全躲藏空間 | 安全 | 準備緊張時可躲避的隱蔽空間，讓貓咪能用自己的速度觀察與適應。 |
| `cat-rest-space` | 休息空間 | 休息 | 日常睡眠與舒適休息的位置要安靜、穩定，避免一直被打擾。 |
| `cat-litter-box` | 貓砂盆 | 排泄 | 貓砂盆應放在安靜、容易到達且與食水分開的位置。 |
| `cat-litter` | 貓砂 | 清潔 | 維持足夠砂量並每天清理，才能觀察排泄與降低壓力。 |
| `cat-food-bowl` | 食盆 | 飲食 | 固定食盆位置，避免和砂盆太接近，讓進食更安心。 |
| `cat-water-bowl` | 水碗 | 飲食 | 水碗可與食盆稍微分開，並每天更換乾淨飲水。 |
| `cat-scratcher` | 抓板 | 活動 | 抓板能提供自然抓磨出口，降低家具被抓的機會。 |
| `cat-tree` | 跳台 | 活動 | 垂直空間能讓貓咪觀察環境、活動與保有安全距離。 |
| `cat-safe-toy` | 安全玩具 | 活動 | 選擇不易吞食、可收納的安全玩具，互動後也要整理。 |

危害物（對應 preparation.ts `catHazards`）：

| ID | 標籤 | danger（風險說明） | handling（處理方式） |
|---|---|---|---|
| `cat-toxic-plants` | 百合／有毒植物 | 百合等植物可能對貓造成嚴重危害，即使少量接觸也應避免。 | 移出貓咪能到達的空間，並確認家中植物是否安全。 |
| `cat-human-medicine` | 人類藥品 | 人用藥品不應自行給貓使用，誤食也可能造成中毒。 | 收到有門的櫃內，並避免把藥放在桌面或包包外層。 |
| `cat-string` | 線狀異物 | 線、繩、橡皮筋等可能被吞食，造成腸胃阻塞或傷害。 | 收進抽屜或盒內，玩具使用後也要收好。 |
| `cat-essential-oil` | 精油／薰香 | 部分精油與薰香對貓不適合，密閉空間中風險更高。 | 避免在貓咪活動區使用，並保持通風與安全距離。 |
| `cat-cleaner` | 清潔劑 | 清潔劑可能刺激皮膚、呼吸道或被舔入體內。 | 使用後確實收納，地面乾燥前避免貓咪進入。 |
| `cat-cooling-product` | 涼感產品 | 部分涼感墊、冰包或凝膠產品若被咬破，可能造成誤食、滑倒或受傷風險。 | 改用通風陰涼處、乾淨飲水與可清洗墊材；降溫用品都要確認材質安全並避免啃咬。 |

**關卡結算提醒**：安全房不等於長期籠飼；應提供可活動、躲藏與垂直空間。

**知識來源**：O3（`貓-居家環境與安全防護.md`）；O1（`貓.md`「居家安全」）

| 用品 ID | 標籤 | description（選取時說明） | caution（注意事項） | feedback（放入後確認） |
|---|---|---|---|---|
| `carrier` | 外出籠 | 外出籠可降低行車途中貓咪在車內移動或逃脫的風險。 | 外出籠尺寸需合適並固定在平坦位置；抵達前不要抱著貓咪直接上下車。 | 外出籠已放入後車廂。 |
| `pee-pad` | 尿墊 | 尿墊可協助處理移動途中可能發生的排泄、嘔吐或髒污。 | 平整鋪在外出籠預定位置下方，並確認不會滑動或被貓咪抓成一團。 | 尿墊已放入後車廂底部。 |
| `water-kit` | 飲水組 | 途中應準備飲水及可使用的水碗，視貓咪狀況與路程在安全停靠處補充。 | 行車中避免開籠餵水，也不要放置裝滿水且容易打翻的開放水碗。 | 水碗與飲水已收妥。 |

> **與犬版差異**：無牽繩；外出籠文案強調固定位置與避免行車中開籠。其餘用品（身分文件、健康資訊等）維持共用架構。

### 5.2 接回家

#### 5.2.1 第一次來到新家（ArrivalSettleActivity）

> **互動機制**：單選處置方式；只有一個完整正確處置可進入正確回饋與第一餐。

**題幹**：到家後，{petName} 待在外出籠裡不願出來。家人擔心牠是不是不喜歡新家。

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 把牠抱出籠，讓牠快點認識新家 | ❌ | 強迫離開外出籠可能讓貓更緊張，也可能引發防衛或躲藏。 |
| 關好門窗，放好食水與砂盆，打開外出籠讓牠自行探索 | ✅ | 保留退路並降低刺激，能幫助貓建立安全感。 |
| 請家人圍過來叫牠，讓牠知道大家都歡迎牠 | ❌ | 多人靠近、聲音與注視會提高剛到家的壓力。 |
| 一進門就打開全屋，讓牠一次探索所有房間 | ❌ | 一次面對整個陌生環境可能增加壓力，也讓牠難以找到可退回的地方。 |

**做得很好回饋**（scenarios.ts `explanation` + `reportSummary`）：保留退路並降低刺激，能幫助貓建立**安全感**。貓咪到家第一天應先進安靜安全的小空間，關好門窗，讓牠自行走出外出籠並用自己的速度探索。

**知識來源**：O5（`貓-適應期教學.md`「到家安置、低干擾原則」）

#### 5.2.2 第一餐（ArrivalMealActivity）

> **互動機制**：完全沿用犬版「第一餐」互動。左側用品架顯示正確食物、乾淨水，以及錯誤食物；玩家將正確食物與水點選／拖曳至食盆、水碗。錯誤食物可點擊查看警示，但不能完成餐點。兩個正確項目都完成才可繼續。

**題幹**：{petName} 剛到新家，還有些不安。先幫牠準備合適的主食與乾淨飲水，讓牠慢慢安心下來。

| 物品 | 分類 | 點擊後回饋 |
|---|---|---|
| 熟悉且符合個體營養需求的貓主食 | ✅ 正確 | 「先維持熟悉食物；若日後轉換新食物，採漸進方式。」 |
| 乾淨飲水 | ✅ 正確 | 「隨時提供乾淨水；不以灌水方式增加攝水。」 |
| 洋蔥／蒜調味的剩菜 | ❌ 錯誤 | 「人類調味食物不適合貓咪，洋蔥、青蔥與大蒜尤其應避免。」 |
| 巧克力或含咖啡因點心 | ❌ 錯誤 | 「這類人類食品可能對貓造成健康危害，不可當作正餐或安撫食物。」 |
| 蔬菜或水果類（對貓咪不適合的種類） | ❌ 錯誤 | 「部分蔬果對貓咪有害；貓咪是肉食性動物，日常主食應以適合的貓主食為主。」 |

> **注意**：依網頁實際內容，第三個錯誤選項為蔬菜／水果類（非「含木糖醇口香糖或人用藥品」），請確認更新後的實際選項文字。

**完成回饋**：「第一餐準備好了。合適主食與乾淨飲水是每天照顧的開始；接下來持續觀察牠的進食、飲水與排泄。」

**知識來源**：O4（`貓-飲食營養與餵食.md`「食物選擇、飲水」）；O5（「到家安置」）

### 5.3 日常照護

#### 5.3.1 日常情境三題

> **互動機制**（沿用現有網頁）：三題皆為複選；每題要選出三個正確做法，避開一個錯誤做法後才能繼續。完成所有正確選項後顯示做得很好回饋。

**題目 1：晚上還很有精神**

**題幹**：晚上你準備休息時，{petName} 開始在家裡奔跑、叫喚，還會撲向晃動的手腳。你會怎麼安排牠的精力與互動？

| 選項 | 正確性 | 回饋方向 |
|---|---|---|
| 用雷射筆讓牠一直追光點，累了自然會睡 | ❌ | 不應使用雷射筆；它可能造成傷害，也沒有能讓貓實際捕捉的目標。 |
| 提供安全玩具或益智漏食玩具，讓牠有合適的活動出口 | ✅ | 安全玩具能分散精力，降低無聊造成的撲咬或叫喚。 |
| 睡前安排短段逗貓棒遊戲，讓牠追逐、捕捉後慢慢收尾 | ✅ | 規律互動能滿足獵捕與活動需求，建立夜間節奏。 |
| 不用手腳直接逗弄，改用玩具保持安全距離 | ✅ | 讓牠追玩具而不是追人的手腳。 |

**做得很好回饋**（scenarios.ts `learningPoints`）：
- 每天安排**逗貓棒互動**，結束前讓牠**成功捕捉**一次；避免單用雷射筆，也不用**手腳直接逗弄**。

**題目 2：抓沙發不是故意搗蛋**

**題幹**：{petName} 最近比較常抓沙發、窗簾和衣櫃邊角，家人擔心家具一直被破壞。你會怎麼引導牠？

| 選項 | 正確性 | 回饋方向 |
|---|---|---|
| 準備穩固抓板或抓柱，放在牠常抓或常經過的位置 | ✅ | 抓板提供自然抓磨出口；位置合適才容易替代家具。 |
| 為了不再抓家具，替牠去爪、磨牙或剃鬍鬚 | ❌ | 除平時清潔與修剪指甲外，不應去爪、磨牙或剃鬍鬚；這些做法不能取代抓磨環境。 |
| 在抓對地方時給鼓勵，並用家具保護或動線調整降低抓錯機會 | ✅ | 替代物搭配環境管理，比只要求牠不要抓更容易穩定。 |
| 整理窗簾、衣櫃與高處路線，確認門窗和紗窗穩固 | ✅ | 抓磨與攀爬可能牽涉安全風險，先整理環境能避免受傷或逃脫。 |

**做得很好回饋**（scenarios.ts `learningPoints`）：
- 提供**位置合適、穩固**的抓板是比阻止更有效的做法；**去爪、磨牙或剃鬍鬚**不應作為處理抓磨的方式。

**題目 3：牠不想出門**

**題幹**：家人覺得貓咪也應該像散步一樣出門走走，但牠看到外出籠就緊張後退。你會怎麼安排？

| 選項 | 正確性 | 回饋方向 |
|---|---|---|
| 看見牠緊張就先停止，不強迫牠出門散步 | ✅ | 尊重壓力訊號能減少恐懼累積。 |
| 直接抱牠出門，多去幾次就會習慣 | ❌ | 強迫外出可能增加恐懼與逃脫風險。 |
| 在室內安排跳台、抓板、安全玩具與陪玩時間 | ✅ | 室內豐富化能滿足活動與互動需求。 |
| 把外出籠放在日常可接觸的位置，慢慢練習需要外出時的安全移動 | ✅ | 平時讓外出籠變成可接受的物品，有助就醫或移動。 |

**做得很好回饋**（scenarios.ts `learningPoints`）：
- 多數貓咪**不需每天外出**，室內豐富化已能滿足日常需求；平時讓**外出籠**成為可接受的物品，就醫時壓力更小。

#### 5.3.2 貓砂盆清潔（LitterBoxActivity）

> **定位**：犬版「散步互動」的對應活動，名稱為**「貓砂盆救援隊」**（journey type: `daily-inspection`）。

**journey.ts 實際配置（`catLitterRescueConfig`）**：

| 參數 | 值 | 說明 |
|---|---|---|
| `targetStamps` | `3` | 需集滿 3 枚印章才通過 |
| `wasteItems` | `[{id:"urine", label:"尿團"}, {id:"poop", label:"糞便"}]` | 可鏟除廢棄物：尿團＋糞便 |
| `enableWeeklyWash` | `false` | **每週清洗日事件尚未開啟** |
| `enableAbnormalObservation` | `false` | **異常觀察事件尚未開啟** |
| `weeklyWashRound` | `2`（預備值） | 第幾輪觸發清洗日（功能關閉中） |
| `abnormalObservationRound` | `3`（預備值） | 第幾輪觸發異常觀察（功能關閉中） |

> **⚠️ 目前實作**：只有鏟除廢棄物＋集 3 枚印章的核心流程。每週清洗日與異常觀察事件的 UI 和邏輯已有設定欄位，但尚未啟用。

**一局流程（現行版本）**：

```
用貓砂鏟找出並鏟除尿團與糞便（wasteItems）
  → 排泄物清除完畢，得到一枚印章
  → 集滿 3 枚印章後通過
```

**設計規格（未來可啟用事件）**：

```
遇到「每週清洗日」（第 weeklyWashRound 輪）：換上備用盆，清洗原盆並選擇完全晾乾
遇到「異常觀察」（第 abnormalObservationRound 輪）：發現排泄改變，記錄並聯繫獸醫
```

**畫面與操作方式**：

1. 畫面中央是一個尺寸足以讓貓轉身的開放式貓砂盆；角落有時段印章、清潔桶、補砂袋與備用盆。
2. 玩家拖曳貓砂鏟掃過可見的尿團與糞便，鏟到後出現足跡提示，直到砂面乾淨。
3. 砂面過淺時露出「無法順利掩埋」提示；玩家點擊補砂袋補足。
4. 每三局隨機出現一次「每週清洗日」：玩家先點選備用盆，再把原盆送去清洗；若直接把濕盆放回去，顯示「需完全晾乾後再使用」並重試。
5. 每次完成得到一枚巡視印章；當天集滿 2–3 枚即顯示「今天的排泄物已定期清除」。不把次數做成漏一次就失敗的壓力機制。

**通關條件**：清除全部可見排泄物、砂量足以掩埋；每週清洗事件中正確使用備用盆並完全晾乾原盆。

| 事件選項 | 結果 | 回饋方向 |
|---|---|---|
| 清除排泄物後發現砂太淺，補足到能掩埋的程度 | ✅ | 足夠砂量能讓貓完成掩埋動作。 |
| 想用濃香芳香劑掩蓋砂盆味道 | ❌ | 氣味可能讓貓排斥；應清除排泄物並定期清洗。 |
| 每週清洗時先換上備用盆，再讓原盆完全晾乾 | ✅ | 清洗期間仍保有可用砂盆，原盆完全乾燥後再使用。 |
| 清洗後直接把還濕的砂盆放回去 | ❌ | 清洗後應完全晾乾；可先以備用盆替換。 |
| 發現排泄困難或顯著改變，先記錄時間與現象並聯絡獸醫 | ✅ | 不能只當作行為問題；紀錄不取代急症處置。 |
| 牠沒上對地方就責罵 | ❌ | 先檢查砂盆、環境與健康可能性，不處罰。 |

**完成回饋**：「砂盆已清潔，砂量也足夠。持續在固定、安靜的位置定期巡視；若發現排泄困難或明顯改變，請聯繫獸醫。」

**知識來源**：O3（砂盆位置與清潔）；O7（排泄觀察與記錄）

**米克斯貓**

### 5.5 生活變化

> **架構對應**：與犬版「生活變化」相同容器，依序包含三個子活動：① BusyCareActivity（忙碌備援計畫）→ ② HealthEventActivity（健康警訊）→ ③ SeniorRoomActivity（高齡期環境調整）

#### 5.5.1 忙碌備援計畫（BusyCareActivity）

> **⚠️ 現行實作（scenarios.ts `cat-busy-care`）**：目前為**單選題**，選到正確選項後直接進入下一關。四項備援確認流程為**設計規格，尚未實作**（程式碼中無對應邏輯），僅作為未來開發參考。

> **互動機制（設計規格）**：情境描述後，玩家從四個選項中選擇如何應對。選到「請可信任的家人或朋友每天來協助」的正確選項後，進入四項備援確認流程，逐一確認準備工作，全部確認後才能通過。

**情境**：你臨時需要出差兩天，{petName} 每天仍需要食水確認、貓砂盆清潔、環境巡視與互動陪玩。

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 出門前多放一些食物和水，回家後再一起處理砂盆和陪玩 | ❌ | 食物和水不能取代砂盆清理、環境巡視和互動；積存的排泄物和長時間沒有陪伴都可能影響 {petName} 的健康與行為。（O7；O1） |
| 請可信任、了解照護需求的家人或朋友每天來協助 | ✅ | 對！交接食水、砂盆、環境巡視與陪玩，才能維持規律照護。進入備援確認流程，確保對方也知道該怎麼做。（O2「代養計畫」；O7 健康警訊） |
| 貓咪很獨立，兩天應該沒問題 | ❌ | 獨立不代表不需要每日照護。砂盆需要定期清潔，{petName} 也需要有人每天確認健康狀況。（O1；O7） |
| 只請人倒飼料，不用特別交代砂盆清潔和觀察 | ❌ | 只補食物會漏掉砂盆、飲水、環境安全與行為變化的確認。（O2；O3） |

**選擇「請家人或朋友每天來協助」後，進入四項備援確認**：

> **互動機制**：每一項確認都有「是」和「還沒 / 不確定」兩個選項。①③④ 描述句為正向敘述（你已經…了嗎），選「是」直接繼續；選「還沒」時顯示說明提醒，顯示「好，我知道了」後才繼續。
>
> **⚠️ 確認②描述句反向**：②改為否定句「我還沒有特別跟協助者說明……」，按鈕標籤與其他項目相同。盲按「是」的玩家等於自己承認還沒說，自然觸發提醒；認真看且已說過的玩家選「不是，我已說過了」直接繼續。不需要追問或反轉邏輯，靠敘述句本身捕捉不認真閱讀的行為。

| 確認項目 | 敘述句 | 選「是」時 | 選「還沒 / 不是」時 |
|---|---|---|---|
| ① 每日照護說明 | 你已經向協助者說明每天需補充食水、清潔貓砂盆、巡視環境並安排短段陪玩了嗎？ | ✅ 直接繼續 | 顯示提醒：貓砂盆每天需清潔；食水、環境巡視與陪玩同樣不可少。請在出發前詳細告知協助者，或把步驟寫下來給他們。→ 顯示「好，我知道了」→ 繼續 |
| ② 24 小時警訊★（描述句反向） | **我還沒有**特別跟協助者說明：{petName} 超過 **24 小時**完全不進食，要立刻通知我 | 玩家確認「是，我還沒說」→ 顯示提醒：貓會隱藏不適，24 小時完全不進食可能讓身體開始消耗自身脂肪，引發嚴重的肝臟問題。協助者如果沒有被特別告知這個警訊，可能以為「貓挑食很正常」，等你回來才發現問題已很嚴重。請出發前一定要特別說明這件事。（O7「健康警訊」）→ 顯示「好，我去說！」→ 繼續 | 玩家表示「不是，我已說過了」→ ✅ 直接繼續 |
| ③ 緊急聯絡方式確認 | 協助者知道緊急時怎麼聯絡到你嗎？ | ✅ 直接繼續 | 顯示提醒：如果 {petName} 出現異狀，協助者需要能立刻聯繫到你。確認你的電話隨時暢通，或提供備用聯絡人，避免緊急時找不到人。→ 顯示「好，我知道了」→ 繼續 |
| ④ 動物醫院資訊共享 | 你已把平常就診的動物醫院聯絡方式和地址給協助者了嗎？ | ✅ 直接繼續 | 顯示提醒：萬一需要緊急就醫，協助者需要知道去哪裡——請事先把動物醫院的名稱、地址和電話傳給他們。（O2「醫療資源」）→ 顯示「好，我知道了」→ 繼續 |

**四項全部確認後顯示**：你已經為 {petName} 做好了充分準備！即使生活有變化，{petName} 也不會被落下。

**知識來源**：O2（`貓-飼養前評估.md`「代養計畫」）；O7（`貓-日常觀察與照護紀錄.md`「健康警訊」）

#### 5.5.2 健康警訊（HealthEventActivity）

> **互動機制**：四選一；正確答案整合觀察紀錄、就醫準備與聯繫獸醫；其他選項分別是等待、只問朋友、或自行用藥等不完整／有風險做法。

**情境**：{petName} 今天吃得比平常少、躲得更久，貓砂盆裡的尿團也明顯減少。你無法確定是壓力還是身體不舒服，但這些改變一起出現了。此刻要先怎麼做？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 記下食慾、飲水、尿便、活動與躲藏的前後變化，準備外出籠與可用資料，並立即聯繫獸醫 | ✅ | 多項變化一起出現時，完整紀錄、就醫準備與聯繫獸醫要一起做；紀錄不能延後急症處置。（O7） |
| 先自行上網查詢症狀，照網友分享的方法在家觀察幾天 | ❌ | 網路資訊和他人經驗不能取代獸醫判斷；明顯變化不應延後聯繫獸醫。 |
| 拍一張照片傳給有養貓的朋友，等對方回覆後再決定 | ❌ | 朋友經驗無法取代獸醫判斷；影像可保留，但仍應主動聯繫獸醫。 |
| 先用家裡的人用藥或剩下的藥物試試看 | ❌ | 未經獸醫指示的藥物可能對貓有害，也會干擾後續判斷。 |

**做得很好回饋**（scenarios.ts `explanation` + `reportSummary`）：多項變化一起出現時，**完整紀錄、就醫準備**與聯繫獸醫要一起做；紀錄不能延後急症處置。貓咪出現食慾、飲水、尿便、活動量或躲藏等明顯改變時，應記錄時間與觀察到的狀況並聯絡獸醫；不要自行判定原因或自行給藥。

**知識來源**：O7（`貓-日常觀察與照護紀錄.md`「每日紀錄、健康警訊、記錄與聯絡獸醫原則」）

#### 5.5.3 高齡期環境調整（SeniorRoomActivity）

> **互動機制**：四選一；唯一正解把如廁、活動、休息與健康追蹤整合為同一套照護方案；其餘三項都是只做一部分或增加負擔的做法。

**情境**：11 歲的 {petName} 最近跳上跳下變慢，進出原本的砂盆也比較猶豫。你想讓牠繼續安全地活動、上廁所與休息，同時建立可長期追蹤的照護節奏。需要怎麼調整？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 增設高度適中的砂盆與地墊、改成階梯式設施並準備保暖休息處；每半年健檢、每週量體重並記錄日常變化 | ✅ | 如廁、活動、休息與健康追蹤一起調整，才能更完整回應高齡生活需求。（O6；O7） |
| 先換成高齡保健配方與關節保健品，平時留意食慾；下次例行就醫時再一起詢問 | ❌ | 飲食或保健品可能是日常照護的一部分，但不能取代眼前的環境調整與獸醫追蹤。 |
| 先在牠常待的角落增加軟墊與保暖處，等牠更不願跳或上砂盆時再調整其他動線 | ❌ | 等到生活困難更明顯才調整，可能錯過減少如廁與活動負擔的時機。 |
| 維持原本高跳台，讓牠多跳一點就會慢慢適應 | ❌ | 忽略行動變化可能增加關節負擔，也可能讓牠減少使用生活空間。 |

**做得很好回饋**（scenarios.ts `explanation` + `reportSummary`）：**如廁、活動、休息與健康追蹤**一起調整，才能更完整回應高齡生活需求。高齡貓需要同步調整如廁、活動、休息與健康追蹤：增設合適砂盆與地墊、階梯式設施、保暖休息處，並定期健檢與記錄變化。

**知識來源**：O6（`貓-各階段照護.md`「高齡期調整」）；O7（「健康追蹤」）

## 七、照顧準備總覽（報告頁）



報告沿用犬版的組成、判定方式與操作：**整體準備程度 → 已準備 → 需要再確認 → 和家人討論 → 下一步行動 → 情境回顧 → 照顧承諾 → 個人資料補充 → 取得寵物**。不以單一分數判定是否可以養貓。

### 7.1 與犬版相同的資料輸入與計算

| 犬版構成 | 貓版對應 |
|---|---|
| 必要用品完成度、危害物完成度、後車廂通關 | 貓安全房必要用品完成度、貓危害物完成度、出發前必備用品通關 |
| 情境第一次答對數、生活練習完成度 | 貓咪情境第一次答對數、第一餐與貓砂盆救援隊完成度 |
| 活動空間、飼養原因、租屋／同住者共識 | 保留相同欄位；活動空間文字改為「貓咪主要活動、躲藏與垂直空間」 |
| 強訊號計算三種準備程度 | 保留相同三段：`已具備多項準備`／`有部分條件需要先確認`／`建議先完成準備事項` |

### 7.2 報告清單內容替換

| 區塊 | 貓版顯示條件／文案 |
|---|---|
| 已準備 | 「必要用品與安全生活空間已完成」；「居家危險物已完成收納與防護」；「接貓用品、文件與安全運輸已通過檢查」；「已完成到家第一餐與貓砂盆救援隊」；「已規劃貓咪的主要活動、躲藏與垂直空間」 |
| 需要再確認 | 「必要用品完成度 {n}%」；「仍有居家危險物需要防護」；「接貓用品尚未通過檢查」；「尚未填寫貓咪預計活動空間」；「尚未填寫飼養原因」；「情境需要再確認：{topic}」 |
| 和家人討論 | 保留「所有同住者是否知情並同意飼養」、「租屋規定與房東書面同意」；增加提示「誰在忙碌、出差或突發狀況時接手食水、砂盆、環境巡視與互動」 |
| 下一步行動 | 「帶著來源、年齡、已知健康與飲食紀錄問題詢問獸醫或領養單位」；「和同住家人確認安全房、門窗防護、日常清潔與備援分工」 |
| 情境回顧 | 首次未答對或協助者確認不完整的題目，開啟知識卡；「忙碌備援計畫」固定顯示：需確認協助者是否真的每天到訪，並了解 24 小時不進食警訊 |
| 照顧承諾 | 保留犬版勾選承諾與解鎖「取得寵物」的機制；文字換為「能持續提供食水、砂盆清理、安全環境、互動、醫療與照護備援」 |
