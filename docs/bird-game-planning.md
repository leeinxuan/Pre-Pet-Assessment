## 一、企劃概述

### 1.1 目標

在既有的「犬版」「貓版」「兔版」飼養前評估遊戲之上，新增**鳥版**內容。鳥版遵循相同的 8 步驟主流程與共用元件架構，所有鳥類專屬內容集中在 `app/data/species/bird/` 設定檔，不重複複製頁面元件、不在元件內散落 `species === "bird"` 條件判斷。

鳥類物種多樣性遠高於犬貓兔，遊戲設計以**通則知識**為主，不細分品種或四類群（鳴禽、陸禽、水禽、攀禽），但情境設計盡量選擇最普遍且具代表性的照護議題。最終照護評估報告說明「鳥類物種差異極大，實際飼養前需對照具體物種」。

### 1.2 鳥的核心照護差異（與犬貓相比）

| 差異點 | 說明 | 遊戲設計重點 |
|---|---|---|
| 鐵氟龍不沾鍋致命 | 高溫加熱鐵氟龍（PTFE）產生的氣體，可在數分鐘內造成鳥中毒死亡 | 空氣安全兩階段情境 + 物種考驗 |
| 食性物種差異大 | 種食性、食蜜性、肉食性、雜食性不可混用飼料；錯誤飼料等於缺乏所有必需營養 | 接回家第一餐選擇 + 物種考驗 |
| 隱藏病徵能力強 | 鳥隱藏病痛的能力極強，看起來精神正常可能已病重；基礎代謝高，病程發展快 | 日常觀察場景 + 物種考驗 |
| 籠具要求精確 | 格柵間距、材質、形狀、棲木寬度都有對應標準；圓形鳥籠對多數鳥不友善 | 房間佈置物品與危險物設計 |
| 空氣品質攸關生命 | 二手煙、線香、漂白水、酒精等揮發物都可能致命；廚房油煙尤其危險 | 房間危險物佈置 + 考驗1 鐵氟龍 |
| 叫聲無法消除 | 鳴叫是物種天性，高互動需求的鸚鵡可能非常吵；事先評估居住環境 | 考驗3 鸚鵡叫聲與居住環境 |
| 野生鳥與保育鸚鵡受法規保護 | 獵捕、走私保育類均違法；發現受傷野鳥應通報，不可自行帶回 | 物種選擇頁 + 照護評估報告 |

## 三、物種選擇階段（Step 1：SpeciesStep）

與犬貓兔相同，固定走**五個子頁面**，對應側欄的五個步驟。鳥版**不進行品種細選**，第二頁「選擇品種」改為隱藏跳過，`selectionId` 固定為 `"bird"`。品種/類群知識不在選擇流程中呈現，分散融入旅程各段落與最終照護評估報告。

### 3.1 子頁面流程（speciesSubPage）

> **鳥版說明**：品種選擇頁（頁 2）對鳥版**隱藏跳過**，`selectionConfig.skipBreedPage: true`，共用元件從頁 1 直接跳至頁 3（取名）。

```
1 選擇物種        → 選擇「鳥」
2 （跳過品種頁）
3 替牠取名        → petName 輸入
4 過往經驗        → 是否養過鳥
5 新的開始        → 過場轉入準備階段
```

---

### 3.2 選擇物種（頁 1）

玩家在物種卡牆選擇「鳥」，與「犬」「貓」「兔」並列。選定後進入頁 3（取名）。

---

### 3.3 選擇品種（頁 2）——鳥版隱藏跳過

> **設計說明**：鳥類物種多樣性過高（超過 11,000 種），遊戲中不呈現品種/類群選擇，`selectionId` 自動設為 `"bird"`。物種多樣性說明（四類群差異、壽命從 10 年到 60 年以上）在最終照護評估報告的「物種認識」面向中呈現。

**報告中應涵蓋的物種認識知識點**（供報告設計參考）：

| 知識點 | 說明 | 來源 |
|---|---|---|
| 壽命差異極大 | 虎皮鸚鵡約 10 年、玄鳳 15–20 年、灰鸚鵡近 50 年、金絲雀約 10–15 年 | B1「概述」 |
| 四類群各有不同需求 | 鳴禽（垂直空間、敏感易驚）、陸禽（平面空間、沙浴）、水禽（水域環境）、攀禽（豐富化設施、社交需求高） | B5 四類群細則 |
| 食性不可混用 | 種食性、食蜜性、肉食性、雜食性，錯誤飼料導致營養缺乏 | B1、B4「食性分類」 |
| 來源必須合法 | 許多鸚鵡受《野生動物保育法》保護，不可飼養野生個體 | B5「鳥的來源」 |

## 四、領養前準備階段（Step 2：Preparation）

### 4.1 佈置鳥的空間（Task 0：RoomPreparation）

玩家在房間畫面中拖放物品，設置鳥的生活環境，並移除危險物品。

#### 4.1.1 應放置的安全物品（roomItems）

| id | 顯示名稱 | 說明文字 | 必要性 | 參考費用 | 知識來源 |
|---|---|---|---|---|---|
| `bird-cage` | 鳥籠（方形、材質適當） | 應選方形金屬鳥籠。圓形籠讓鳥無邊角可倚靠休憩，長期承受精神壓力；格柵間隙需依鳥體型選擇，不可過大（逃脫/卡傷）也不可過小（通風不良）。 | 必要 | 800 元（300–1,500） | B1「鳥籠與棲木」；B4「鳥籠的選擇」 |

| `incense-candle` | 線香/薰香蠟燭 | 鳥的呼吸道極敏感，揮發性物質（線香、薰香、精油）可能造成呼吸道傷害甚至中毒。 | B4「空氣品質」 |

#### 5.2.1 抵達轉場

**場景說明**：{petName} 在外出籠裡，跟著你回到家了。畫面顯示「{petName} 到家了！」過場畫面（AssetPlaceholder：`bird-arrival-animation`），無互動，自動進入下一幕。

#### 5.2.2 {petName} 到家了，你第一件事？（ArrivalSettleActivity）

**情境**：你把外出籠帶進房間。{petName} 在籠內靜靜站在棲木上，左右張望，羽毛微微膨起。

**問題**：你現在會怎麼做？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 立刻把 {petName} 從外出籠移到鳥籠，讓牠趕快適應新家 | ⚠️ 操之過急 | 環境轉換本身就是強烈的壓力。建議先把外出籠放在鳥籠旁，讓 {petName} 自行決定探索的時機，不要在這個當下強迫移動，避免雙重緊迫。（B5「如何挑選合適的鳥」；B4 適應期原則） |
| 把外出籠放在安靜的固定位置，蓋上遮光布，讓 {petName} 在黑暗中平靜下來 | ✅ 正確 | 對！新環境的光線刺激和陌生氣味都會造成壓力。輕輕蓋上遮光布，讓 {petName} 在熟悉的封閉感中逐漸放鬆，是最溫和的安置方式。（B4「溫度」；B5 適應期） |
| 邀請全家人圍過來看 {petName}，讓牠快點認識大家 | ❌ 不適當 | 多人圍觀是極大的視覺和聽覺刺激，可能造成嚴重緊迫。應保持安靜，讓 {petName} 在最少干擾的環境中慢慢適應。（B5「如何挑選」互動需求；B3 社交模式） |
| 立刻讓 {petName} 出籠，在房間自由飛翔 | ❌ 危險 | 在尚未確認房間安全（無逃脫路徑、無危險物品）的情況下讓鳥飛出，可能造成撞傷或逃跑。適應期應先在籠內穩定後，再計畫安全的籠外活動時間。（B4「攜帶外出」；B5） |

**答對時顯示（做得很好）**

**鼓勵話語**：你選擇了最溫和的安置方式！給 {petName} 安靜的空間和熟悉的遮光感，是讓牠在新環境第一天保持平靜的最佳選擇，做得很好。

**鳥類小知識**：新環境對鳥是一種強烈的感官衝擊——陌生的氣味、聲音和視覺刺激都會引發緊迫反應。鳥在緊迫時的表現包括：羽毛膨起、呼吸急促、過度鳴叫或反而異常安靜。遮光布能提供「封閉感」，讓鳥在適應期的第一階段有足夠的安全感。多數鳥需要 1–2 週才能在新環境中真正放鬆。

**知識來源**：B5（`鳥類-四類群照養細則.md`「如何挑選合適的鳥」互動需求段落）；B4 溫度與空氣品質；B3 社交模式

#### 5.3.2 鳥籠日常巡視（BirdCageInspectionActivity）

> **定位**：以「拖拉清潔糞便托盤」、「點擊觀察糞便」、「點擊檢視健康狀態」、「開籠社交互動」為核心互動，讓玩家實際操作一次完整的每日照護流程（journey type: `daily-inspection`）。**移除補充飼料與更換飲水步驟**（已有獨立餵食互動頁面，不重複）；無選擇題；完成後顯示三段式完成畫面（參考犬版散步互動頁面結構）。

**一局流程**：
```
步驟 1：拖曳糞便托盤滑出籠底 → 拖刮刀清除糞便 → 拖新墊料（報紙）鋪上 → 推回托盤
  → 步驟 2：清出的糞便放大展示，玩家點擊觀察（探索，非問答）
  → 步驟 3：點擊 {petName} 身體各部位觀察健康指標（探索式，四個部位全點完）
  → 步驟 4：點擊籠門鎖扣解鎖，{petName} 飛出，玩家點擊 {petName} 完成互動
  → 全部完成 → 進入完成畫面
```

**畫面與操作方式**：
1. 場景是一個方形金屬鳥籠，籠中有兩根棲木（不同高度、不同材質），{petName} 站在其中一根上。籠底有可向右拉出的**糞便托盤**。
2. **步驟 1：清潔糞便托盤** — 玩家**向右拖曳托盤**，托盤滑出籠底，顯示昨天積累的糞便與舊墊料。接著玩家**按住拖曳刮刀**在托盤上掃過，糞便清入廢棄桶（計數顯示「清潔完成」）；再**拖曳一張墊料（報紙圖示）**蓋上托盤，**向左推回**托盤到原位。步驟完成音效。
3. **步驟 2：觀察糞便（探索，非問答）** — 廢棄桶旁的糞便樣本自動放大，玩家**點擊糞便樣本**，彈出觀察卡說明：形態、顏色、尿酸量是否正常，以及這樣的糞便代表什麼。糞便隨機為三種之一（健康 / 水狀異色 / 量少配合食量下降），觀察卡告訴玩家是否需要注意，無對錯評分。
4. **步驟 3：觀察 {petName} 健康狀態（探索式）** — 畫面中 {petName} 站在棲木上，身上出現四個點擊提示點（👁️ 眼睛、🪶 羽毛、🦵 腳和棲木、💨 呼吸狀況）。玩家**依序點擊各部位**，每個部位彈出一張說明卡，說明「今天觀察到的狀態」與「需要注意的警訊」（例：眼睛清亮無分泌物為正常；出現澎毛、無法站棲木、張口呼吸則為緊急警訊）。四個部位全點擊完成後解鎖下一步。
5. **步驟 4：籠外社交時間** — 畫面出現提示：「{petName} 今天需要在籠外活動和陪伴」。玩家**點擊籠門鎖扣**解鎖，籠門打開，{petName} 飛出停在玩家手上（動畫）。玩家可**點擊 {petName}** 一到兩次觸發互動（點頭、鳴叫動畫），完成互動後步驟完成。

#### 考驗 1：家裡這個鍋子，你必須丟掉

**挑戰標題**：鐵氟龍不沾鍋……和鳥不能共存？

**情境**：你的父母說：「鐵氟龍鍋很方便，我們用了幾十年都沒事，鳥又不在廚房，應該不會怎樣吧？」

**問題**：關於鐵氟龍不沾鍋與養鳥，以下哪個描述正確？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 鳥不在廚房，離遠一點就好，不需要換鍋 | ❌ 錯誤 | 鐵氟龍加熱後產生的有毒氣體會擴散到整個室內空間，不只是廚房。鳥的呼吸系統極敏感，即使在其他房間也可能受影響。距離無法作為保護。（B1「空氣品質」；B4） |
| 只要不讓鍋燒過頭，偶爾用一下沒關係 | ❌ 錯誤 | 鐵氟龍在高溫下（約 260°C 以上）開始分解，這在日常烹飪中很容易達到。「燒過頭」的判斷對人來說有時也難以察覺，不可靠。（B1「空氣品質」） |
| 家中有養鳥，必須完全停用鐵氟龍鍋具，改用不鏽鋼或鑄鐵鍋 | ✅ 正確 | 對！這是養鳥前必須做的準備。鐵氟龍（聚四氟乙烯，PTFE）高溫分解產生的四氟乙烯氣體，可能讓鳥在短時間內死亡。這不是誇大，是有記錄的事故。（B1、B4「空氣品質」） |
| 只要不在鳥在場的時候開火，鐵氟龍應該沒問題 | ❌ 錯誤 | 有毒氣體不會因為「鳥暫時不在場」就消失，氣體擴散到室內的時間可能讓鳥回籠後仍接觸到。且實際操作中很難完全控制時機。（B4「空氣品質」） |

**答對時顯示（做得很好）**

**鼓勵話語**：你選擇了正確答案！這代表你真的認識到養鳥生活裡那些「必須改變的事」，而不只是把鳥帶回家就算完成了，做得很好。

**鳥類小知識**：鐵氟龍（PTFE）不沾鍋是養鳥家庭必須面對的一個真實改變。鐵氟龍高溫後分解的氣體，可能讓鳥在極短時間內死亡——這不是謠言，是有記錄的真實案例。養鳥的家庭必須將家中所有鐵氟龍鍋具全部汰換，改用不鏽鋼鍋、鑄鐵鍋，這是養鳥前無法省略的準備。除了鐵氟龍，線香、薰香、漂白水、二手煙，都是對鳥呼吸系統的威脅。

**知識來源**：B1（`鳥類.md`「生活環境與溫度・空氣品質」）；B4（`鳥類-飲食營養與環境設備.md`「空氣品質」）

**鳥類小知識**：很多人沒有意識到，養一隻大型鸚鵡，可能是一個比養狗更長的承諾。灰鸚鵡壽命可達 40–60 年，金剛鸚鵡更長——這意味著你需要在遺囑中為牠安排監護人。即使是常見的虎皮鸚鵡，在良好照護下也能活超過 10 年。壽命不只是一個數字，它代表著你接下來每一年，都要為 {petName} 提供照顧、陪伴、醫療和情感連結。

#### 考驗 3：鸚鵡的叫聲，你真的準備好了嗎？

**挑戰標題**：牠很可愛，但牠也很……吵

**情境**：領養 {petName} 之前，你在寵物店看到牠安靜地站在棲木上，樣子很可愛。但最近，你住在隔壁的朋友家也有養鸚鵡——每天早上牠會持續大叫半小時，連你的房間都聽得到。你開始思考：這是正常的嗎？我的居住環境能接受嗎？

**問題**：關於養鸚鵡的叫聲，以下哪個說法正確？

| 選項 | 正確性 | 回饋 |
|---|---|---|
| 只要從小訓練，鸚鵡就不會亂叫了 | ❌ 錯誤 | 鸚鵡的鳴叫是天性，不是「壞習慣」，無法透過訓練完全消除。鳴叫是牠的溝通方式——表達興奮、呼喚注意、宣示領域都可能引發叫聲。試圖完全壓制叫聲反而可能造成心理問題。（B1「行為與活動需求」；B5「評估自身生活習慣」） |
| 晚上蓋上籠布，就可以解決叫聲問題 | ❌ 不完整 | 蓋上籠布有助於夜間安靜，但白天（尤其是日出前後）的鳴叫是鸚鵡天性，籠布無法阻止。中大型鸚鵡的叫聲最高可達 80 分貝以上，在公寓環境可能引起鄰居困擾。（B1「行為與活動需求」；B2「飼養前評估」） |
| 飼養前應評估居住環境是否能接受鸚鵡的叫聲——包括自己、家人和鄰居 | ✅ 正確 | 對！鸚鵡的鳴叫量與音量是飼養前必須誠實評估的現實。中大型鸚鵡在需要互動時叫聲非常洪亮；即使是小型虎皮鸚鵡，每日也有固定的活躍鳴叫時段。如果居住環境無法長期接受，養鸚鵡可能成為雙方的痛苦。（B2「飼養前評估」；B5「行為社交需求」） |
| 把鸚鵡單獨關在密閉房間，就能控制叫聲又不影響家人 | ❌ 危險 | 將鸚鵡完全隔離在密閉空間，可能因空氣品質惡化、溫度失控和社交剝奪造成嚴重壓力。高互動需求的鸚鵡若長期缺乏社交，可能出現拔毛、重複性行為等心理問題。（B4「空氣品質」；B5「鸚鵡心理健康」） |

**答對時顯示（做得很好）**

**鼓勵話語**：你選擇了最重要的一點——飼養前誠實評估自己的居住條件！很多人在被鸚鵡可愛的外表吸引後，才發現叫聲是他們無法長期承受的現實，做得很好。

**鳥類小知識**：鸚鵡的鳴叫是牠的天性語言：呼喚注意、表達情緒、與同伴溝通。你無法讓牠完全不叫，但可以透過充足的社交互動和豐富化設施，減少因「無聊」或「焦慮」引發的過度鳴叫。飼養高互動需求的攀禽（鸚鵡類），每天可能需要 1–2 小時以上的籠外社交時間——這不只是個人喜好，而是維持鸚鵡心理健康的必要條件。

**知識來源**：B2（`鳥類-飼養前評估.md`「行為、互動與混養」）；B1（`鳥類.md`「行為與活動需求」）；B5（`鳥類-四類群照養細則.md`「評估自身生活習慣」；「攀禽」）

| 將棲木調低，降低跌落風險 | ✅ 正確 | 高齡鳥體力和平衡感下降，較低的棲木能降低跌落傷害的風險。可保留一根較高的棲木讓牠自行選擇。（B3「生命階段・老年期」；B4 棲木） |
| 提高健檢頻率，從一年一次改為更頻繁 | ✅ 正確 | 老年鳥更容易出現代謝疾病、心血管疾病、白內障和腫瘤。提高健檢頻率能提前發現問題。（B3「生命階段・老年期」；B5 健康管理） |
| 高齡鳥不再需要豐富化設施，讓牠安靜休息就好 | ❌ 錯誤 | 即使活動力下降，適合老年鳥的豐富化（簡單的啃咬玩具、低難度的益智設施）仍有助於心理健康，不應完全撤除所有刺激。（B4「環境豐富化」） |
| 活動力明顯下降後，可以逐漸減少每天的籠外互動時間，讓牠多休息 | ❌ 錯誤 | 老年期的社交陪伴仍然重要，強制剝奪互動反而可能加速心理退化。應依個體狀況調整互動方式，而非直接縮短時間。（B5「鸚鵡心理健康」；B3「老年期」） |

> **通關機制**：玩家必須同時勾選兩個 ✅ 選項、不勾選兩個 ❌ 選項才算通過。只選一個正確選項不算完成。

**全部正確時顯示（做得很好）**

**鼓勵話語**：你知道高齡照護不只是「讓牠安靜休息」，而是需要主動調整環境和加強醫療觀察，做得很好！

**鳥類小知識**：高齡鳥的照護重點是「安全 + 舒適 + 密切觀察」。降低跌落風險、提高健檢頻率、維持穩定溫度、諮詢飲食調整——這些都是讓 {petName} 在老年期維持生活品質的方法。每隻鳥的老化速度不同，鳥類獸醫師的定期評估是最可靠的依據。如果 {petName} 正經歷無法復原的痛苦，安樂死也是由獸醫師專業評估的醫療選項，這是照護責任的一部分。

**知識來源**：B3（`鳥類-生理與行為.md`「生命階段・老年期」；「體溫調節」）；B4（`鳥類-飲食營養與環境設備.md`「環境豐富化」；「溫度」）；B5（`鳥類-四類群照養細則.md`「健康管理・安樂死」）
